Raspberry Pi Pico vs Arduino Nano

The two boards side by side, from the same board files BoardPilot uses to check your wiring.

Default SPIMOSI GP19, MISO GP16, SCK GP18MOSI D11, MISO D12, SCK D13
5 V tolerant inputsnoyes
Flashing toolpicotool (UF2)avrdude
Arduino boardrp2040:rp2040:rpipicoarduino:avr:nano

Which one to pick?

  • Pick the Raspberry Pi Pico if you need more GPIO pins (26), the faster processor.
  • Pick the Arduino Nano if you need 5 V signals without level shifters, more analog inputs (8).
