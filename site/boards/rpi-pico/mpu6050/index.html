MPU6050 with Raspberry Pi Pico

Wiring for the MPU6050 (GY-521) accelerometer + gyro on the Raspberry Pi Pico (RP2040, 3.3 V logic), chosen with the same pin rules BoardPilot uses: default buses first, and no pins that are used for flash, USB, the debugger or booting.

Check before you power it on

  • Supply: 3.3 V from the 3V3(OUT) pin.
  • I2C uses the board’s default pins GP4 (SDA) and GP5 (SCL). Most modules include pull-up resistors; if the part is not found, check them and swap-test SDA/SCL.
  • To make sure it is the real chip, read register 0x75: a genuine part answers 0x68.

Good to know

  • The address is 0x68, or 0x69 when AD0 is HIGH. (InvenSense MPU-6000/MPU-6050 Product Specification, I²C interface: slave address)
  • It starts in sleep mode and reads zeros until PWR_MGMT_1 (0x6B) is cleared. Libraries do this in begin(); your own code must too. (InvenSense MPU-6000/MPU-6050 Register Map, Register 107, Power Management 1 (reset value 0x40, sleep))

Test code (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = GP4, SCL = GP5 (the board's default I2C pins)
  Wire.beginTransmission(0x68);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "MPU6050 (GY-521) accelerometer + gyro found at 0x68" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Arduino board: rp2040:rp2040:rpipico. If the board is not found, hold the BOOTSEL button while plugging in the USB cable.

Questions

Which Raspberry Pi Pico pins do I use for the MPU6050?

VCC → 3V3(OUT), GND → GND, SCL → GP5, SDA → GP4, INT → GP15.

Does the MPU6050 work with the Raspberry Pi Pico at 3.3 V?

Yes: the MPU6050 runs at 3.3-5 V and the Raspberry Pi Pico uses 3.3 V signals, so no level shifting is needed.

What is the I2C address of the MPU6050?

0x68 or 0x69. An I2C scan (BoardPilot does it for you) shows which one your module uses.
