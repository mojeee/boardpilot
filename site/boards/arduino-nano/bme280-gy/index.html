BME280 with Arduino Nano

Wiring for the GY-BME280 breakout on the Arduino Nano (ATmega328P, 5 V logic), chosen with the same pin rules BoardPilot uses: default buses first, and no pins that are used for flash, USB, the debugger or booting.

Wiring

VINPower3V3
GNDGroundGND
SCLI2C clock (SCL)A5 (PC5)
SDAI2C data (SDA)A4 (PC4)

Check before you power it on

  • Supply: 3.3 V from the 3V3 pin.
  • The BME280 is a 3.3 V part and the Arduino Nano uses 5 V signals. Power it from 3.3 V and put a level shifter on the signal wires, or buy a 5 V version of the module.
  • I2C uses the board’s default pins A4 (SDA) and A5 (SCL). Most modules include pull-up resistors; if the part is not found, check them and swap-test SDA/SCL.
  • To make sure it is the real chip, read register 0xD0: a genuine part answers 0x60.

Good to know

  • Many boards sold as BME280 carry a BMP280, which has no humidity sensor. The chip ID register 0xD0 tells them apart: 0x60 is a BME280, 0x58 a BMP280. (Bosch BME280 and BMP280 datasheets, Register 0xD0 “id”)
  • Read in normal mode at a high rate, the sensor warms itself and reads high. For weather readings use forced mode, about one reading per minute. (Bosch BME280 datasheet, Recommended modes of operation: weather monitoring)

Test code (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = A4, SCL = A5 (the board's default I2C pins)
  Wire.beginTransmission(0x76);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "GY-BME280 breakout found at 0x76" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Arduino board: arduino:avr:nano. Clones with the old bootloader upload at 57600 baud: choose “ATmega328P (Old Bootloader)” if uploads fail.

Questions

Which Arduino Nano pins do I use for the BME280?

VIN → 3V3, GND → GND, SCL → A5 (PC5), SDA → A4 (PC4).

Does the BME280 work with the Arduino Nano at 5 V?

The BME280 is a 3.3 V part and the Arduino Nano uses 5 V signals. Power it from 3.3 V and put a level shifter on the signal wires, or buy a 5 V version of the module.

What is the I2C address of the BME280?

0x76 or 0x77. An I2C scan (BoardPilot does it for you) shows which one your module uses.
