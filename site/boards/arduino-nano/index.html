Arduino Nano pinout

A small, breadboard-friendly Arduino with the same chip as the Uno. It uses 5 V logic, so 3.3 V-only sensors need a level shifter.

Pins to avoid or use with care

Input only: A6 (ADC6), A7 (ADC7)

Cannot drive outputs, and have no internal pull-up.

USB serial: RX0 (PD0), TX1 (PD1)

Used for uploading and the serial monitor. Anything connected here can break uploads.

Good pins for LEDs, buttons and signals

D2, D3, D4, D5, D6, D7, D8, D9

Default pins in Arduino

I2C
SDA = A4, SCL = A5. Only these pins work with the Wire library defaults. I2C only works on A4 (SDA) and A5 (SCL).
SPI
MOSI = D11, MISO = D12, SCK = D13, CS = D10.
Analog inputs
A0, A1, A2, A3, A6, A7, A4, A5 (0–5 V)

How to flash it

Clones with the old bootloader upload at 57600 baud: choose “ATmega328P (Old Bootloader)” if uploads fail.

Questions

Which pins are I2C on the Arduino Nano?

SDA is A4 and SCL is A5 (the defaults of the Arduino Wire library). Only certain pins support I2C in hardware, so use these unless you know your core allows others.

Which Arduino Nano pins should I avoid?

RX0, TX1 (USB serial link); A6, A7 (input only).

Is the Arduino Nano 5 V tolerant?

The Arduino Nano runs at 5 V, so 5 V sensors connect directly. 3.3 V-only parts need a level shifter.

Which pins can read analog voltage on the Arduino Nano?

A0, A1, A2, A3, A6, A7, A4, A5, from 0 to 5 V.

How do I upload code to the Arduino Nano?

In the Arduino IDE pick the board arduino:avr:nano (core arduino:avr). Clones with the old bootloader upload at 57600 baud: choose “ATmega328P (Old Bootloader)” if uploads fail.
