Push button with Raspberry Pi Pico W

Wiring for the Push button on the Raspberry Pi Pico W (RP2040, 3.3 V logic), chosen with the same pin rules BoardPilot uses: default buses first, and no pins that are used for flash, USB, the debugger or booting.

Wiring

Push button pinRoleRaspberry Pi Pico W pinNotes
1Output from the partGP15To a GPIO; use INPUT_PULLUP in code
2GroundGND

Check before you power it on

    Good to know

    • An input with nothing pulling it reads random values. Use INPUT_PULLUP and wire the button to GND: pressed reads LOW. (Arduino reference, Digital pins: INPUT_PULLUP)
    • The contacts bounce for a few milliseconds, so one press can count as several. Debounce in code. (Arduino examples, Debounce)

    Test code (Arduino)

    void setup() {
  Serial.begin(115200);
  pinMode(15, INPUT_PULLUP);  // pressed = LOW
}

void loop() {
  Serial.println(digitalRead(15) == LOW ? "pressed" : "released");
  delay(100);
}

    Arduino board: rp2040:rp2040:rpipicow. If the board is not found, hold the BOOTSEL button while plugging in the USB cable.

    Questions

    Which Raspberry Pi Pico W pins do I use for the Push button?

    1 → GP15, 2 → GND.

    Does the Push button work with the Raspberry Pi Pico W at 3.3 V?

    Yes: the Push button runs at 3.3 V and the Raspberry Pi Pico W uses 3.3 V signals, so no level shifting is needed.
