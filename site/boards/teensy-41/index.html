Teensy 4.1 pinout

A very fast (600 MHz) breadboard-friendly board with native USB, lots of serial, I2C and SPI ports and a microSD slot. 3.3 V logic; the pins are not 5 V tolerant.

Pins to avoid or use with care

None on the header.

Good pins for LEDs, buttons and signals

2, 3, 4, 5, 6, 9, 28, 29, 30, 31, 32, 33

Default pins in Arduino

I2C
SDA = 18, SCL = 19. Only these pins work with the Wire library defaults. Wire only works on pins 18 (SDA) and 19 (SCL). Wire1 uses 17 (SDA1) and 16 (SCL1); Wire2 uses 25 (SDA2) and 24 (SCL2).
SPI
MOSI = 11, MISO = 12, SCK = 13, CS = 10.
Analog inputs
14, 15, 16, 17, 20, 21, 22, 23, 24, 25, 26, 27, 38, 39, 40, 41, 18, 19 (0–3.3 V)

Questions

Which pins are I2C on the Teensy 4.1?

SDA is 18 and SCL is 19 (the defaults of the Arduino Wire library). Only certain pins support I2C in hardware, so use these unless you know your core allows others.

Which Teensy 4.1 pins should I avoid?

No header pin is reserved for flash, USB or the debugger; the power and ground pins are the only ones that are not GPIO.

Is the Teensy 4.1 5 V tolerant?

No. The pins take at most 3.3 V. Use a level shifter or a voltage divider for 5 V signals.

Which pins can read analog voltage on the Teensy 4.1?

14, 15, 16, 17, 20, 21, 22, 23, 24, 25, 26, 27, 38, 39, 40, 41, 18, 19, from 0 to 3.3 V.

How do I upload code to the Teensy 4.1?

In the Arduino IDE pick the board teensy:avr:teensy41 (core teensy:avr). Press the white program button once if the upload waits for the board.
