AHT20 with Teensy 4.1

Wiring for the AHT20 temperature + humidity on the Teensy 4.1 (MIMXRT1062DVJ6B, 3.3 V logic), chosen with the same pin rules BoardPilot uses: default buses first, and no pins that are used for flash, USB, the debugger or booting.

Wiring

AHT20 pinRoleTeensy 4.1 pinNotes
VINPower3V
GNDGroundG
SCLI2C clock (SCL)19 (GPIO_AD_B1_00)
SDAI2C data (SDA)18 (GPIO_AD_B1_01)

Check before you power it on

  • Supply: 3.3 V from the 3V pin.
  • I2C uses the board’s default pins 18 (SDA) and 19 (SCL). Most modules include pull-up resistors; if the part is not found, check them and swap-test SDA/SCL.

Good to know

  • Its address is fixed at 0x38: one per bus. The DHT20 uses the same chip and the same address. (Aosong AHT20 datasheet, Sensor address 0x38)
  • After power-up, wait 40 ms; each measurement takes about 80 ms. (Aosong AHT20 datasheet, Sensor reading process)

Test code (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = 18, SCL = 19 (the board's default I2C pins)
  Wire.beginTransmission(0x38);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "AHT20 temperature + humidity found at 0x38" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Arduino board: teensy:avr:teensy41. Press the white program button once if the upload waits for the board.

Questions

Which Teensy 4.1 pins do I use for the AHT20?

VIN → 3V, GND → G, SCL → 19 (GPIO_AD_B1_00), SDA → 18 (GPIO_AD_B1_01).

Does the AHT20 work with the Teensy 4.1 at 3.3 V?

Yes: the AHT20 runs at 3.3-5 V and the Teensy 4.1 uses 3.3 V signals, so no level shifting is needed.

What is the I2C address of the AHT20?

0x38. An I2C scan (BoardPilot does it for you) shows which one your module uses.
