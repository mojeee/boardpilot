BMP280 with Teensy 4.1

Wiring for the GY-BMP280 pressure + temperature on the Teensy 4.1 (MIMXRT1062DVJ6B, 3.3 V logic), chosen with the same pin rules BoardPilot uses: default buses first, and no pins that are used for flash, USB, the debugger or booting.

Wiring

VCCPower3V
GNDGroundG
SCLI2C clock (SCL)19 (GPIO_AD_B1_00)
SDAI2C data (SDA)18 (GPIO_AD_B1_01)

Check before you power it on

  • Supply: 3.3 V from the 3V pin.
  • I2C uses the board’s default pins 18 (SDA) and 19 (SCL). Most modules include pull-up resistors; if the part is not found, check them and swap-test SDA/SCL.
  • To make sure it is the real chip, read register 0xD0: a genuine part answers 0x58.

Good to know

  • It measures temperature and pressure only, no humidity. If your code asks for humidity, you need a BME280. (Bosch BMP280 datasheet, Product description)
  • The address is 0x76 with SDO to GND and 0x77 with SDO high. Most GY boards answer at 0x76, while the Adafruit library looks at 0x77 unless you pass 0x76. (Bosch BMP280 datasheet, I²C interface, slave address)

Test code (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = 18, SCL = 19 (the board's default I2C pins)
  Wire.beginTransmission(0x76);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "GY-BMP280 pressure + temperature found at 0x76" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Arduino board: teensy:avr:teensy41. Press the white program button once if the upload waits for the board.

Questions

Which Teensy 4.1 pins do I use for the BMP280?

VCC → 3V, GND → G, SCL → 19 (GPIO_AD_B1_00), SDA → 18 (GPIO_AD_B1_01).

Does the BMP280 work with the Teensy 4.1 at 3.3 V?

Yes: the BMP280 runs at 3.3 V and the Teensy 4.1 uses 3.3 V signals, so no level shifting is needed.

What is the I2C address of the BMP280?

0x76 or 0x77. An I2C scan (BoardPilot does it for you) shows which one your module uses.
