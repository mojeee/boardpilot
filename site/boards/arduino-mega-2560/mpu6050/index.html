Check before you power it on

  • Supply: 5 V from the 5V pin.
  • I2C uses the board’s default pins SDA 20 (SDA) and SCL 21 (SCL). Most modules include pull-up resistors; if the part is not found, check them and swap-test SDA/SCL.
  • To make sure it is the real chip, read register 0x75: a genuine part answers 0x68.

Good to know

  • The address is 0x68, or 0x69 when AD0 is HIGH. (InvenSense MPU-6000/MPU-6050 Product Specification, I²C interface: slave address)
  • It starts in sleep mode and reads zeros until PWR_MGMT_1 (0x6B) is cleared. Libraries do this in begin(); your own code must too. (InvenSense MPU-6000/MPU-6050 Register Map, Register 107, Power Management 1 (reset value 0x40, sleep))

Test code (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = SDA 20, SCL = SCL 21 (the board's default I2C pins)
  Wire.beginTransmission(0x68);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "MPU6050 (GY-521) accelerometer + gyro found at 0x68" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Arduino board: arduino:avr:mega.

Questions

Which Arduino Mega 2560 R3 pins do I use for the MPU6050?

VCC → 5V, GND → GND, SCL → SCL 21 (PD0), SDA → SDA 20 (PD1), INT → ~2 (PE4).

Does the MPU6050 work with the Arduino Mega 2560 R3 at 5 V?

Yes: the MPU6050 runs at 3.3-5 V and the Arduino Mega 2560 R3 uses 5 V signals, so no level shifting is needed.

What is the I2C address of the MPU6050?

0x68 or 0x69. An I2C scan (BoardPilot does it for you) shows which one your module uses.
