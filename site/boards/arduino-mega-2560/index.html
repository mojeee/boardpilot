Arduino Mega 2560 R3 pinout

A big Arduino with 54 digital pins, 16 analog inputs and 4 serial ports. It uses 5 V logic, so 3.3 V-only sensors need a level shifter.

Pins to avoid or use with care

USB serial: TX0→1 (PE1), RX0←0 (PE0)

Used for uploading and the serial monitor. Anything connected here can break uploads.

Default pins in Arduino

I2C
SDA = SDA 20, SCL = SCL 21. Only these pins work with the Wire library defaults. I2C only works on 20 (SDA) and 21 (SCL); the SDA/SCL pins near AREF are the same signals. Both have 10 kΩ pull-ups to 5 V on the board.
SPI
MOSI = 51, MISO = 50, SCK = 52, CS = 53.
Analog inputs
A0, A1, A2, A3, A4, A5, A6, A7, A8, A9, A10, A11, A12, A13, A14, A15 (0–5 V)

Questions

Which pins are I2C on the Arduino Mega 2560 R3?

SDA is SDA 20 and SCL is SCL 21 (the defaults of the Arduino Wire library). Only certain pins support I2C in hardware, so use these unless you know your core allows others.

Which Arduino Mega 2560 R3 pins should I avoid?

TX0→1, RX0←0 (USB serial link).

Is the Arduino Mega 2560 R3 5 V tolerant?

The Arduino Mega 2560 R3 runs at 5 V, so 5 V sensors connect directly. 3.3 V-only parts need a level shifter.

Which pins can read analog voltage on the Arduino Mega 2560 R3?

A0, A1, A2, A3, A4, A5, A6, A7, A8, A9, A10, A11, A12, A13, A14, A15, from 0 to 5 V.

How do I upload code to the Arduino Mega 2560 R3?

In the Arduino IDE pick the board arduino:avr:mega (core arduino:avr).
