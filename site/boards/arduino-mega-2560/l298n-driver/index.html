L298N with Arduino Mega 2560 R3

Check before you power it on

  • Motors, servos, relays and LED strips can draw more current than the Arduino Mega 2560 R3’s pins or USB can give. Power them separately and connect the grounds together.

Test code (Arduino)

// Motor A: ENA = speed (PWM), IN1/IN2 = direction. Remove the ENA jumper on the module.
void setup() {
  pinMode(23, OUTPUT);
  pinMode(24, OUTPUT);
  pinMode(22, OUTPUT);
}

void loop() {
  digitalWrite(23, HIGH);
  digitalWrite(24, LOW);
  analogWrite(22, 180);  // about 70% speed
  delay(2000);
  analogWrite(22, 0);    // stop
  delay(1000);
}

Arduino board: arduino:avr:mega.

Questions

Which Arduino Mega 2560 R3 pins do I use for the L298N?

ENA → 22 (PA0), IN1 → 23 (PA1), IN2 → 24 (PA2), IN3 → 25 (PA3), IN4 → 26 (PA4), ENB → 27 (PA5), GND → GND.

Does the L298N work with the Arduino Mega 2560 R3 at 5 V?

Yes: the L298N runs at 5 V and the Arduino Mega 2560 R3 uses 5 V signals, so no level shifting is needed.
