LED with Nordic nRF52840 DK

Wiring for the LED with 220 Ω resistor on the Nordic nRF52840 DK (nRF52840-QIAA, 3.3 V logic), chosen with the same pin rules BoardPilot uses: default buses first, and no pins that are used for flash, USB, the debugger or booting.

    Test code (Arduino)

    The Arduino core for this board numbers its pins differently from the chip names, so no code is shown here. Use the pin names from your core’s variant file.

    Arduino board: adafruit:nrf52:pca10056. Plug USB into the port on the short edge (interface MCU, J2) and set the power switch to ON; before the first Arduino sketch, burn the Adafruit bootloader and SoftDevice once.

    Questions

    Which Nordic nRF52840 DK pins do I use for the LED?

    A → P1.03, K → GND.

    Does the LED work with the Nordic nRF52840 DK at 3.3 V?

    Yes: the LED runs at 3.3 V and the Nordic nRF52840 DK uses 3.3 V signals, so no level shifting is needed.
