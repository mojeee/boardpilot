Test code (Arduino)

The Arduino core for this board numbers its pins differently from the chip names, so no code is shown here. Use the pin names from your core’s variant file.

Arduino board: adafruit:nrf52:pca10056. Plug USB into the port on the short edge (interface MCU, J2) and set the power switch to ON; before the first Arduino sketch, burn the Adafruit bootloader and SoftDevice once.

Questions

Which Nordic nRF52840 DK pins do I use for the SD card module?

GND → GND, 3V3 → 5V, CS → P1.12, MOSI → P1.13, SCK → P1.15, MISO → P1.14, GND2 → GND.

Does the SD card module work with the Nordic nRF52840 DK at 3.3 V?

Yes: the SD card module runs at 3.3-5 V and the Nordic nRF52840 DK uses 3.3 V signals, so no level shifting is needed.
