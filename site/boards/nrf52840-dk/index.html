Nordic nRF52840 DK pinout

Nordic's official development kit for the nRF52840 Bluetooth chip, with a built-in J-Link debugger, 4 buttons, 4 LEDs and Arduino-style headers. Pins run at 3.0 V and are not 5 V tolerant.

At a glance

Chip
nRF52840-QIAA (nRF52840)
Processor
Arm Cortex-M4F at 64 MHz, 256 KB RAM, 1 MB flash, Bluetooth LE, Thread/Zigbee (802.15.4), NFC, native USB

Pins to avoid or use with care

Flash memory: P0.17, P0.19, P0.21, P0.23, P0.20, P0.22

Wired to the flash memory. Never use them.

USB serial: P0.08, P0.06

Used for uploading and the serial monitor. Anything connected here can break uploads.

Used on the board: P0.10, P0.09, P0.08, P0.07, P0.06, P0.05, P0.01, P0.00, P0.11, P0.17, P0.19, P0.21, P0.23, P0.25, P0.12, P0.18, P0.20, P0.22, P0.24, P1.00

Already connected to something on the board (see the notes in the table).

Good pins for LEDs, buttons and signals

P1.03, P1.04, P1.05, P1.06, P1.10, P1.11, P1.07, P1.08

Default pins in Arduino

I2C
SDA = P0.26, SCL = P0.27. Only these pins work with the Wire library defaults. The nRF52840 I2C (TWIM) block can use almost any pin, but the Arduino core's Wire is fixed to P0.26 (SDA) and P0.27 (SCL), the Arduino SDA/SCL sockets.
SPI
MOSI = P1.13, MISO = P1.14, SCK = P1.15, CS = P1.12.
Analog inputs
P0.03 (A0), P0.04, P0.28, P0.29, P0.30, P0.31 (0–3.6 V)

How to flash it

Plug USB into the port on the short edge (interface MCU, J2) and set the power switch to ON; before the first Arduino sketch, burn the Adafruit bootloader and SoftDevice once.

Questions

Which pins are I2C on the Nordic nRF52840 DK?

SDA is P0.26 and SCL is P0.27 (the defaults of the Arduino Wire library). Only certain pins support I2C in hardware, so use these unless you know your core allows others.

Which Nordic nRF52840 DK pins should I avoid?

P0.17, P0.19, P0.21, P0.23, P0.20, P0.22 (flash memory); P0.08, P0.06 (USB serial link); P0.10, P0.09, P0.08, P0.07, P0.06, P0.05, P0.01, P0.00, P0.11, P0.17, P0.19, P0.21, P0.23, P0.25, P0.12, P0.18, P0.20, P0.22, P0.24, P1.00 (used on the board).

Is the Nordic nRF52840 DK 5 V tolerant?

No. The pins take at most 3.3 V. Use a level shifter or a voltage divider for 5 V signals.

Which pins can read analog voltage on the Nordic nRF52840 DK?

P0.03 (A0), P0.04, P0.28, P0.29, P0.30, P0.31, from 0 to 3.6 V.

How do I upload code to the Nordic nRF52840 DK?

In the Arduino IDE pick the board adafruit:nrf52:pca10056 (core adafruit:nrf52). Plug USB into the port on the short edge (interface MCU, J2) and set the power switch to ON; before the first Arduino sketch, burn the Adafruit bootloader and SoftDevice once.
