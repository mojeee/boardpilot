SD card module with ESP32-C3-DevKitM-1

Wiring for the SD card module (full size, SPI) on the ESP32-C3-DevKitM-1 (ESP32-C3, 3.3 V logic), chosen with the same pin rules BoardPilot uses: default buses first, and no pins that are used for flash, USB, the debugger or booting.

Check before you power it on

  • Supply: 3.3 V from the 3V3 pin.

Good to know

  • The SD library reads FAT16 and FAT32 cards. Cards formatted as exFAT (most over 32 GB) are not found. (Arduino SD library reference, Supported file systems: FAT16 and FAT32)

Test code (Arduino)

// Library: SD (built in)
#include <SPI.h>
#include <SD.h>

void setup() {
  Serial.begin(115200);
  if (!SD.begin(7)) {
    Serial.println("No card: check wiring, the card format (FAT32) and power");
    return;
  }
  File f = SD.open("/test.txt", FILE_WRITE);
  f.println("Hello from the board");
  f.close();
  Serial.println("Wrote test.txt");
}

void loop() {}

Arduino board: esp32:esp32:esp32c3. If uploading does not start, hold BOOT, press and release RST, then release BOOT.

Questions

Which ESP32-C3-DevKitM-1 pins do I use for the SD card module?

GND → GND, 3V3 → 3V3, CS → 7, MOSI → 6, SCK → 4, MISO → 5, GND2 → GND.

Does the SD card module work with the ESP32-C3-DevKitM-1 at 3.3 V?

Yes: the SD card module runs at 3.3-5 V and the ESP32-C3-DevKitM-1 uses 3.3 V signals, so no level shifting is needed.
