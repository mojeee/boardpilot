Check before you power it on

  • Supply: 3.3 V from the 3V3 pin.
  • I2C uses the board’s default pins B7 (SDA) and B6 (SCL). Most modules include pull-up resistors; if the part is not found, check them and swap-test SDA/SCL.
  • To make sure it is the real chip, read register 0xFF: a genuine part answers 0x15.

Test code (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = B7, SCL = B6 (the board's default I2C pins)
  Wire.beginTransmission(0x57);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "MAX30102 heart rate + SpO2 found at 0x57" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Arduino board: STMicroelectronics:stm32:GenF4:pnum=BLACKPILL_F411CE,usb=CDCgen,upload_method=dfuMethod. To upload over USB, hold BOOT0, press and release NRST, then release BOOT0 (DFU mode). An ST-LINK on the SWD pins also works.

Questions

Which WeAct Black Pill STM32F411CE pins do I use for the MAX30102?

VIN → 3V3, SDA → B7 (PB7), SCL → B6 (PB6), INT → A0 (PA0), GND → G.

Does the MAX30102 work with the WeAct Black Pill STM32F411CE at 3.3 V?

Yes: the MAX30102 runs at 3.3-5 V and the WeAct Black Pill STM32F411CE uses 3.3 V signals, so no level shifting is needed.

What is the I2C address of the MAX30102?

0x57. An I2C scan (BoardPilot does it for you) shows which one your module uses.
