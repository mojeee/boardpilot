Test code (Arduino)

void setup() {
  Serial.begin(115200);
  analogReadResolution(12);
}

void loop() {
  long mv = (long)analogRead(PA1) * 3300L / 4095;  // OUT on A1
  Serial.println(mv);
  delay(200);
}

Arduino board: STMicroelectronics:stm32:GenF4:pnum=BLACKPILL_F411CE,usb=CDCgen,upload_method=dfuMethod. To upload over USB, hold BOOT0, press and release NRST, then release BOOT0 (DFU mode). An ST-LINK on the SWD pins also works.

Questions

Which WeAct Black Pill STM32F411CE pins do I use for the Potentiometer?

VCC → 3V3, OUT → A1 (PA1), GND → G.

Does the Potentiometer work with the WeAct Black Pill STM32F411CE at 3.3 V?

Yes: the Potentiometer runs at 3.3 V and the WeAct Black Pill STM32F411CE uses 3.3 V signals, so no level shifting is needed.
