Check before you power it on

  • Supply: 3.3 V from the 3V3 pin.
  • I2C uses the board’s default pins B7 (SDA) and B6 (SCL). Most modules include pull-up resistors; if the part is not found, check them and swap-test SDA/SCL.

Good to know

  • Each input must stay between GND and VDD, even in differential mode. The default range is ±2.048 V; set the gain for larger signals. (TI ADS111x datasheet, Absolute maximum ratings: analog input; PGA full-scale range (default ±2.048 V))

Test code (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = B7, SCL = B6 (the board's default I2C pins)
  Wire.beginTransmission(0x48);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "ADS1115 16-bit ADC found at 0x48" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Arduino board: STMicroelectronics:stm32:GenF4:pnum=BLACKPILL_F411CE,usb=CDCgen,upload_method=dfuMethod. To upload over USB, hold BOOT0, press and release NRST, then release BOOT0 (DFU mode). An ST-LINK on the SWD pins also works.

Questions

Which WeAct Black Pill STM32F411CE pins do I use for the ADS1115?

VDD → 3V3, GND → G, SCL → B6 (PB6), SDA → B7 (PB7), ALRT → A0 (PA0).

Does the ADS1115 work with the WeAct Black Pill STM32F411CE at 3.3 V?

Yes: the ADS1115 runs at 3.3-5 V and the WeAct Black Pill STM32F411CE uses 3.3 V signals, so no level shifting is needed.

What is the I2C address of the ADS1115?

0x48 or 0x49 or 0x4A or 0x4B. An I2C scan (BoardPilot does it for you) shows which one your module uses.
