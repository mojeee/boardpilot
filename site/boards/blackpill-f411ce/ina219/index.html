INA219 with WeAct Black Pill STM32F411CE

Wiring for the INA219 current + voltage monitor on the WeAct Black Pill STM32F411CE (STM32F411CE, 3.3 V logic), chosen with the same pin rules BoardPilot uses: default buses first, and no pins that are used for flash, USB, the debugger or booting.

Check before you power it on

  • Supply: 3.3 V from the 3V3 pin.
  • I2C uses the board’s default pins B7 (SDA) and B6 (SCL). Most modules include pull-up resistors; if the part is not found, check them and swap-test SDA/SCL.

Good to know

  • With the usual 0.1 Ω shunt it measures up to 3.2 A (±320 mV across the shunt), and the bus voltage up to 26 V. (TI INA219 datasheet, Electrical characteristics: shunt voltage range ±320 mV, bus voltage 0 to 26 V)
  • Put it in series on the positive side: supply + to VIN+, VIN− to the load. (TI INA219 datasheet, Typical application: high-side sensing)

Test code (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = B7, SCL = B6 (the board's default I2C pins)
  Wire.beginTransmission(0x40);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "INA219 current + voltage monitor found at 0x40" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Arduino board: STMicroelectronics:stm32:GenF4:pnum=BLACKPILL_F411CE,usb=CDCgen,upload_method=dfuMethod. To upload over USB, hold BOOT0, press and release NRST, then release BOOT0 (DFU mode). An ST-LINK on the SWD pins also works.

Questions

Which WeAct Black Pill STM32F411CE pins do I use for the INA219?

VCC → 3V3, GND → G, SCL → B6 (PB6), SDA → B7 (PB7).

Does the INA219 work with the WeAct Black Pill STM32F411CE at 3.3 V?

Yes: the INA219 runs at 3.3-5 V and the WeAct Black Pill STM32F411CE uses 3.3 V signals, so no level shifting is needed.

What is the I2C address of the INA219?

0x40 or 0x41 or 0x44 or 0x45. An I2C scan (BoardPilot does it for you) shows which one your module uses.
