BME280 with WeAct Black Pill STM32F411CE

Check before you power it on

  • Supply: 3.3 V from the 3V3 pin.
  • I2C uses the board’s default pins B7 (SDA) and B6 (SCL). Most modules include pull-up resistors; if the part is not found, check them and swap-test SDA/SCL.
  • To make sure it is the real chip, read register 0xD0: a genuine part answers 0x60.

Good to know

  • Many boards sold as BME280 carry a BMP280, which has no humidity sensor. The chip ID register 0xD0 tells them apart: 0x60 is a BME280, 0x58 a BMP280. (Bosch BME280 and BMP280 datasheets, Register 0xD0 “id”)
  • Read in normal mode at a high rate, the sensor warms itself and reads high. For weather readings use forced mode, about one reading per minute. (Bosch BME280 datasheet, Recommended modes of operation: weather monitoring)

Test code (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = B7, SCL = B6 (the board's default I2C pins)
  Wire.beginTransmission(0x76);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "GY-BME280 breakout found at 0x76" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Arduino board: STMicroelectronics:stm32:GenF4:pnum=BLACKPILL_F411CE,usb=CDCgen,upload_method=dfuMethod. To upload over USB, hold BOOT0, press and release NRST, then release BOOT0 (DFU mode). An ST-LINK on the SWD pins also works.

Questions

Which WeAct Black Pill STM32F411CE pins do I use for the BME280?

VIN → 3V3, GND → G, SCL → B6 (PB6), SDA → B7 (PB7).

Does the BME280 work with the WeAct Black Pill STM32F411CE at 3.3 V?

Yes: the BME280 runs at 3.3 V and the WeAct Black Pill STM32F411CE uses 3.3 V signals, so no level shifting is needed.

What is the I2C address of the BME280?

0x76 or 0x77. An I2C scan (BoardPilot does it for you) shows which one your module uses.
