Raspberry Pi Pico 2 pinout

The second-generation Pico with the faster RP2350 chip, twice the memory and 4 MB flash. Same 40-pin layout as the Pico, 3.3 V logic.

At a glance

Chip
RP2350 (RP2350A)
Processor
Dual-core Arm Cortex-M33 or RISC-V Hazard3 at 150 MHz, 520 KB SRAM, 4 MB flash
Logic level
3.3 V. Not 5 V tolerant unless marked below.
Flashing tool
picotool (UF2)
Arduino board (FQBN)
rp2040:rp2040:rpipico2
Live pin view in BoardPilot
Yes (diagnostic agent available)

Pins to avoid or use with care

Debug port: SWCLK, SWDIO

SWD/JTAG. Using them can stop a debugger from reaching the chip.

Good pins for LEDs, buttons and signals

GP15, GP14, GP13, GP12, GP11, GP10, GP22, GP21, GP20, GP6, GP7, GP2, GP3

Default pins in Arduino

I2C
SDA = GP4, SCL = GP5. Only these pins work with the Wire library defaults. Only certain pin pairs can be I2C on this chip, and SDA and SCL cannot be swapped in software. Wire uses GP4 (SDA) and GP5 (SCL); Wire.setSDA()/Wire.setSCL() before Wire.begin() can move I2C0 to GP0/GP1, GP8/GP9, GP12/GP13, GP16/GP17 or GP20/GP21. Wire1 defaults to GP26/GP27.
SPI
MOSI = GP19, MISO = GP16, SCK = GP18, CS = GP17.
Analog inputs
GP26, GP27, GP28 (0–3.3 V)
5 V tolerant pins
GP0, GP1, GP2, GP3, GP4, GP5, GP6, GP7, GP8, GP9, GP10, GP11, GP12, GP13, GP14, GP15, GP16, GP17, GP18, GP19, GP20, GP21, GP22

How to flash it

If the board is not found, hold the BOOTSEL button while plugging in the USB cable.

Questions

Which pins are I2C on the Raspberry Pi Pico 2?

SDA is GP4 and SCL is GP5 (the defaults of the Arduino Wire library). Only certain pins support I2C in hardware, so use these unless you know your core allows others.

Which Raspberry Pi Pico 2 pins should I avoid?

SWCLK, SWDIO (debug port).

Is the Raspberry Pi Pico 2 5 V tolerant?

The chip runs at 3.3 V, but these pins tolerate 5 V inputs: GP0, GP1, GP2, GP3, GP4, GP5, GP6, GP7, GP8, GP9, GP10, GP11, GP12, GP13, GP14, GP15, GP16, GP17, GP18, GP19, GP20, GP21, GP22. The others take at most 3.3 V.

Which pins can read analog voltage on the Raspberry Pi Pico 2?

GP26, GP27, GP28, from 0 to 3.3 V.

How do I upload code to the Raspberry Pi Pico 2?

In the Arduino IDE pick the board rp2040:rp2040:rpipico2 (core rp2040:rp2040). If the board is not found, hold the BOOTSEL button while plugging in the USB cable.
