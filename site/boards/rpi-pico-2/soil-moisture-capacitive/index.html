Capacitive soil moisture sensor with Raspberry Pi Pico 2

Wiring for the Capacitive soil moisture sensor v1.2 on the Raspberry Pi Pico 2 (RP2350, 3.3 V logic), chosen with the same pin rules BoardPilot uses: default buses first, and no pins that are used for flash, USB, the debugger or booting.

Check before you power it on

  • Supply: 3.3 V from the 3V3(OUT) pin.

Test code (Arduino)

void setup() {
  Serial.begin(115200);
  analogReadResolution(12);
}

void loop() {
  long mv = (long)analogRead(26) * 3300L / 4095;  // AOUT on GP26
  Serial.println(mv);
  delay(200);
}

Arduino board: rp2040:rp2040:rpipico2. If the board is not found, hold the BOOTSEL button while plugging in the USB cable.

Questions

Which Raspberry Pi Pico 2 pins do I use for the Capacitive soil moisture sensor?

GND → GND, VCC → 3V3(OUT), AOUT → GP26.

Does the Capacitive soil moisture sensor work with the Raspberry Pi Pico 2 at 3.3 V?

Yes: the Capacitive soil moisture sensor runs at 3.3-5 V and the Raspberry Pi Pico 2 uses 3.3 V signals, so no level shifting is needed.
