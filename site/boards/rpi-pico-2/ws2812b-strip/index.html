WS2812B LED strip with Raspberry Pi Pico 2

Wiring for the WS2812B addressable LED strip on the Raspberry Pi Pico 2 (RP2350, 3.3 V logic), chosen with the same pin rules BoardPilot uses: default buses first, and no pins that are used for flash, USB, the debugger or booting.

Wiring

5VPowerVBUSUse VBUS for a few LEDs; a separate 5 V supply for more (up to 60 mA per LED)

Check before you power it on

  • Supply: 5 V from the VBUS pin.
  • Motors, servos, relays and LED strips can draw more current than the Raspberry Pi Pico 2’s pins or USB can give. Power them separately and connect the grounds together.

Good to know

  • Each LED draws up to about 60 mA at full white: 30 LEDs need about 1.8 A, more than USB gives. Power the strip from its own 5 V supply and connect the grounds. (Adafruit NeoPixel Überguide, Powering NeoPixels)
  • Put a 300 to 500 Ω resistor in the data line and a large capacitor (about 1000 µF) across the strip’s supply. (Adafruit NeoPixel Überguide, Best practices)
  • on 3.3 V boards: At 5 V the data input needs at least 0.7 × 5 V = 3.5 V to read HIGH. A 3.3 V board often works but not always: a level shifter (74AHCT125) makes it reliable. (Worldsemi WS2812B datasheet, Electrical characteristics: VIH = 0.7 VDD)

Test code (Arduino)

// Library: Adafruit NeoPixel
#include <Adafruit_NeoPixel.h>

Adafruit_NeoPixel strip(8, 15, NEO_GRB + NEO_KHZ800);  // 8 LEDs

void setup() {
  strip.begin();
  strip.setBrightness(40);  // keep it low when powered from USB
}

void loop() {
  for (int i = 0; i < strip.numPixels(); i++) {
    strip.clear();
    strip.setPixelColor(i, strip.Color(0, 80, 255));
    strip.show();
    delay(100);
  }
}

Arduino board: rp2040:rp2040:rpipico2. If the board is not found, hold the BOOTSEL button while plugging in the USB cable.

Questions

Which Raspberry Pi Pico 2 pins do I use for the WS2812B LED strip?

5V → VBUS, DIN → GP15, GND → GND.

Does the WS2812B LED strip work with the Raspberry Pi Pico 2 at 3.3 V?

Yes: the WS2812B LED strip runs at 5 V and the Raspberry Pi Pico 2 uses 3.3 V signals, so no level shifting is needed.
