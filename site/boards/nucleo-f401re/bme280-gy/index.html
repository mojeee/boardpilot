BME280 with NUCLEO-F401RE

Wiring for the GY-BME280 breakout on the NUCLEO-F401RE (STM32F401RE, 3.3 V logic), chosen with the same pin rules BoardPilot uses: default buses first, and no pins that are used for flash, USB, the debugger or booting.

Check before you power it on

  • Supply: 3.3 V from the 3V3 pin.
  • I2C uses the board’s default pins SDA/D14 (SDA) and SCL/D15 (SCL). Most modules include pull-up resistors; if the part is not found, check them and swap-test SDA/SCL.
  • To make sure it is the real chip, read register 0xD0: a genuine part answers 0x60.

Good to know

  • Many boards sold as BME280 carry a BMP280, which has no humidity sensor. The chip ID register 0xD0 tells them apart: 0x60 is a BME280, 0x58 a BMP280. (Bosch BME280 and BMP280 datasheets, Register 0xD0 “id”)
  • Read in normal mode at a high rate, the sensor warms itself and reads high. For weather readings use forced mode, about one reading per minute. (Bosch BME280 datasheet, Recommended modes of operation: weather monitoring)

Test code (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = SDA/D14, SCL = SCL/D15 (the board's default I2C pins)
  Wire.beginTransmission(0x76);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "GY-BME280 breakout found at 0x76" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Arduino board: STMicroelectronics:stm32:Nucleo_64:pnum=NUCLEO_F401RE. Plug the USB cable into the mini-USB port on the ST-LINK end. No button press is needed.

Questions

Which NUCLEO-F401RE pins do I use for the BME280?

VIN → 3V3, GND → GND, SCL → SCL/D15 (PB8), SDA → SDA/D14 (PB9).

Does the BME280 work with the NUCLEO-F401RE at 3.3 V?

Yes: the BME280 runs at 3.3 V and the NUCLEO-F401RE uses 3.3 V signals, so no level shifting is needed.

What is the I2C address of the BME280?

0x76 or 0x77. An I2C scan (BoardPilot does it for you) shows which one your module uses.
