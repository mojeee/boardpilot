LCD 1602 I2C with NUCLEO-F401RE

Wiring for the LCD 16x2 with I2C backpack on the NUCLEO-F401RE (STM32F401RE, 3.3 V logic), chosen with the same pin rules BoardPilot uses: default buses first, and no pins that are used for flash, USB, the debugger or booting.

Check before you power it on

  • Supply: 5 V from the 5V pin.
  • I2C uses the board’s default pins SDA/D14 (SDA) and SCL/D15 (SCL). Most modules include pull-up resistors; if the part is not found, check them and swap-test SDA/SCL.

Test code (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = SDA/D14, SCL = SCL/D15 (the board's default I2C pins)
  Wire.beginTransmission(0x20);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "LCD 16x2 with I2C backpack found at 0x20" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Arduino board: STMicroelectronics:stm32:Nucleo_64:pnum=NUCLEO_F401RE. Plug the USB cable into the mini-USB port on the ST-LINK end. No button press is needed.

Questions

Which NUCLEO-F401RE pins do I use for the LCD 1602 I2C?

GND → GND, VCC → 5V, SDA → SDA/D14 (PB9), SCL → SCL/D15 (PB8).

Does the LCD 1602 I2C work with the NUCLEO-F401RE at 3.3 V?

Yes: the LCD 1602 I2C runs at 5 V and the NUCLEO-F401RE uses 3.3 V signals, so no level shifting is needed.

What is the I2C address of the LCD 1602 I2C?

0x20 or 0x21 or 0x22 or 0x23 or 0x24 or 0x25 or 0x26 or 0x27 or 0x38 or 0x39 or 0x3A or 0x3B or 0x3C or 0x3D or 0x3E or 0x3F. An I2C scan (BoardPilot does it for you) shows which one your module uses.
