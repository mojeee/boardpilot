ST NUCLEO-F401RE pinout

ST's official STM32F401 board with Arduino Uno style sockets and a built-in ST-LINK programmer and debugger. 3.3 V logic, most pins tolerate 5 V.

Pins to avoid or use with care

Strapping pins: BOOT0, PB2

Their level at reset changes how the board boots. Usually fine after boot.

USB serial: RX/D0 (PA3), TX/D1 (PA2)

Used for uploading and the serial monitor. Anything connected here can break uploads.

Debug port: PA13, PA14

SWD/JTAG. Using them can stop a debugger from reaching the chip.

Used on the board: RX/D0 (PA3), TX/D1 (PA2), PC13, PC14, PC15, PH0, PH1

Already connected to something on the board (see the notes in the table).

Good pins for LEDs, buttons and signals

D2, D4, PWM/D5, PWM/D6, D7, D8, PWM/D9, PWM/D3, PWM/CS/D10, PWM/MOSI/D11, MISO/D12

Default pins in Arduino

I2C
SDA = SDA/D14, SCL = SCL/D15. Only these pins work with the Wire library defaults. Wire uses PB9 (D14) for SDA and PB8 (D15) for SCL. Only specific STM32 pin pairs can do I2C (for example PB7/PB6 with Wire.setSDA/setSCL).
SPI
MOSI = PWM/MOSI/D11, MISO = MISO/D12, SCK = SCK/D13, CS = PWM/CS/D10.
Analog inputs
A0, A1, A2, A3, A4, A5 (0–3.3 V)
5 V tolerant pins
RX/D0 (PA3), TX/D1 (PA2), D2 (PA10), PWM/D3 (PB3), D4 (PB5), PWM/D5 (PB4), PWM/D6 (PB10), D7 (PA8), D8 (PA9), PWM/D9 (PC7), PWM/CS/D10 (PB6), PWM/MOSI/D11 (PA7), MISO/D12 (PA6), SCK/D13 (PA5), SDA/D14 (PB9), SCL/D15 (PB8), A0 (PA0), A1 (PA1), A2 (PA4), A3 (PB0), A4 (PC1), A5 (PC0), PC10, PC11, PC12, PD2, PA13, PA14, PA15, PB7, PC13, PC14, PC15, PH0, PH1, PC2, PC3, PC9, PC8, PC6, PC5, PA12, PA11, PB12, PB2, PB1, PB15, PB14, PB13, PC4

How to flash it

Plug the USB cable into the mini-USB port on the ST-LINK end. No button press is needed.

Questions

Which pins are I2C on the NUCLEO-F401RE?

SDA is SDA/D14 and SCL is SCL/D15 (the defaults of the Arduino Wire library). Only certain pins support I2C in hardware, so use these unless you know your core allows others.

Which NUCLEO-F401RE pins should I avoid?

PA13, PA14 (debug port); RX/D0, TX/D1 (USB serial link); RX/D0, TX/D1, PC13, PC14, PC15, PH0, PH1 (used on the board).

Is the NUCLEO-F401RE 5 V tolerant?

The chip runs at 3.3 V, but these pins tolerate 5 V inputs: RX/D0, TX/D1, D2, PWM/D3, D4, PWM/D5, PWM/D6, D7, D8, PWM/D9, PWM/CS/D10, PWM/MOSI/D11, MISO/D12, SCK/D13, SDA/D14, SCL/D15, A0, A1, A2, A3, A4, A5, PC10, PC11, PC12, PD2, PA13, PA14, PA15, PB7, PC13, PC14, PC15, PH0, PH1, PC2, PC3, PC9, PC8, PC6, PC5, PA12, PA11, PB12, PB2, PB1, PB15, PB14, PB13, PC4. The others take at most 3.3 V.

Which pins can read analog voltage on the NUCLEO-F401RE?

A0, A1, A2, A3, A4, A5, from 0 to 3.3 V.

How do I upload code to the NUCLEO-F401RE?

In the Arduino IDE pick the board STMicroelectronics:stm32:Nucleo_64:pnum=NUCLEO_F401RE (core STMicroelectronics:stm32). Plug the USB cable into the mini-USB port on the ST-LINK end. No button press is needed.
