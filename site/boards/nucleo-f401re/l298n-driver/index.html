L298N with NUCLEO-F401RE

Wiring for the L298N dual motor driver on the NUCLEO-F401RE (STM32F401RE, 3.3 V logic), chosen with the same pin rules BoardPilot uses: default buses first, and no pins that are used for flash, USB, the debugger or booting.

Check before you power it on

  • Motors, servos, relays and LED strips can draw more current than the NUCLEO-F401RE’s pins or USB can give. Power them separately and connect the grounds together.

Good to know

  • The L298 loses about 2 to 3 V inside: a motor on a 6 V supply gets roughly 4 V. Connect the driver’s GND to the board’s GND. (ST L298 datasheet, Total drop (source + sink saturation voltage))

Test code (Arduino)

// Motor A: ENA = speed (PWM), IN1/IN2 = direction. Remove the ENA jumper on the module.
void setup() {
  pinMode(PB5, OUTPUT);
  pinMode(PB4, OUTPUT);
  pinMode(PA10, OUTPUT);
}

void loop() {
  digitalWrite(PB5, HIGH);
  digitalWrite(PB4, LOW);
  analogWrite(PA10, 180);  // about 70% speed
  delay(2000);
  analogWrite(PA10, 0);    // stop
  delay(1000);
}

Arduino board: STMicroelectronics:stm32:Nucleo_64:pnum=NUCLEO_F401RE. Plug the USB cable into the mini-USB port on the ST-LINK end. No button press is needed.

Questions

Which NUCLEO-F401RE pins do I use for the L298N?

ENA → D2 (PA10), IN1 → D4 (PB5), IN2 → PWM/D5 (PB4), IN3 → PWM/D6 (PB10), IN4 → D7 (PA8), ENB → D8 (PA9), GND → GND.

Does the L298N work with the NUCLEO-F401RE at 3.3 V?

Yes: the L298N runs at 5 V and the NUCLEO-F401RE uses 3.3 V signals, so no level shifting is needed.
