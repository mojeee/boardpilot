ESP32-S3-DevKitC-1 pinout

Espressif's own ESP32-S3 board: Wi-Fi, Bluetooth LE, two USB ports and an RGB LED. Breadboard friendly, 3.3 V logic.

Pins to avoid or use with care

Flash memory: 37, 36, 35

Wired to the flash memory. Never use them.

Boot-critical strapping pins: 45

A wrong level at reset stops the board from booting.

Strapping pins: 3, 46, 0

Their level at reset changes how the board boots. Usually fine after boot.

USB serial: TX (GPIO43), RX (GPIO44)

Used for uploading and the serial monitor. Anything connected here can break uploads.

Native USB: 20, 19

The USB data lines. Using them breaks USB uploads and the serial monitor.

Good pins for LEDs, buttons and signals

4, 5, 6, 7, 15, 16, 17, 18, 21, 47, 1, 2, 14

Default pins in Arduino

I2C
SDA = 8, SCL = 9. Any output-capable pins work with Wire.begin(sda, scl). Any GPIO can be I2C on the ESP32-S3. Arduino's Wire uses GPIO 8 (SDA) and GPIO 9 (SCL) by default.
SPI
MOSI = 11, MISO = 13, SCK = 12, CS = 10.
Analog inputs
1, 2, 4, 5, 6, 7, 10, 3, 8, 9 (0–3.3 V)

How to flash it

Use the port labelled UART. If uploading does not start, hold BOOT, press and release RESET, then release BOOT.

Questions

Which pins are I2C on the ESP32-S3-DevKitC-1?

SDA is 8 and SCL is 9 (the defaults of the Arduino Wire library). You can move I2C to other pins with Wire.begin(sda, scl).

Which ESP32-S3-DevKitC-1 pins should I avoid?

37, 36, 35 (flash memory); 45 (stops booting if held at the wrong level); 20, 19 (native USB); TX, RX (USB serial link).

Is the ESP32-S3-DevKitC-1 5 V tolerant?

No. The pins take at most 3.3 V. Use a level shifter or a voltage divider for 5 V signals.

Which pins can read analog voltage on the ESP32-S3-DevKitC-1?

1, 2, 4, 5, 6, 7, 10, 3, 8, 9, from 0 to 3.3 V.

How do I upload code to the ESP32-S3-DevKitC-1?

In the Arduino IDE pick the board esp32:esp32:esp32s3 (core esp32:esp32). Use the port labelled UART. If uploading does not start, hold BOOT, press and release RESET, then release BOOT.
