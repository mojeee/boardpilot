BMP280 with ESP32-S3-DevKitC-1

Wiring for the GY-BMP280 pressure + temperature on the ESP32-S3-DevKitC-1 (ESP32-S3, 3.3 V logic), chosen with the same pin rules BoardPilot uses: default buses first, and no pins that are used for flash, USB, the debugger or booting.

Wiring

BMP280 pinRoleESP32-S3-DevKitC-1 pinNotes
VCCPower3V3
GNDGroundG
SCLI2C clock (SCL)9
SDAI2C data (SDA)8
CSBNot wired to the boardnot connectedChip select. Leave unconnected (pulled HIGH on the board) to use I2C
SDONot wired to the boardnot connectedAddress select: LOW = 0x76, HIGH = 0x77. Most boards default to 0x76

Check before you power it on

  • Supply: 3.3 V from the 3V3 pin.
  • I2C can use almost any pins on the ESP32-S3-DevKitC-1; 8 (SDA) and 9 (SCL) are the defaults. If the part is not found, the wires may be crossed: try Wire.begin with the two exchanged.
  • To make sure it is the real chip, read register 0xD0: a genuine part answers 0x58.

Test code (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin(8, 9);  // SDA = 8, SCL = 9
  Wire.beginTransmission(0x76);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "GY-BMP280 pressure + temperature found at 0x76" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Arduino board: esp32:esp32:esp32s3. Use the port labelled UART. If uploading does not start, hold BOOT, press and release RESET, then release BOOT.

Questions

Which ESP32-S3-DevKitC-1 pins do I use for the BMP280?

VCC → 3V3, GND → G, SCL → 9, SDA → 8.

Does the BMP280 work with the ESP32-S3-DevKitC-1 at 3.3 V?

Yes: the BMP280 runs at 3.3 V and the ESP32-S3-DevKitC-1 uses 3.3 V signals, so no level shifting is needed.

What is the I2C address of the BMP280?

0x76 or 0x77. An I2C scan (BoardPilot does it for you) shows which one your module uses.
