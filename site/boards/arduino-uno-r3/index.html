Arduino Uno R3 pinout

The classic Arduino board for learning. It uses 5 V logic, so 3.3 V-only sensors need a level shifter.

At a glance

Chip
ATmega328P
Processor
8-bit AVR ATmega328P at 16 MHz, 2 KB SRAM, 32 KB flash, 1 KB EEPROM
Logic level
5 V. 3.3 V-only sensors need a level shifter.
Flashing tool
avrdude
Arduino board (FQBN)
arduino:avr:uno
Live pin view in BoardPilot
Yes (diagnostic agent available)

Pins to avoid or use with care

USB serial: TX→1 (PD1), RX←0 (PD0)

Used for uploading and the serial monitor. Anything connected here can break uploads.

Good pins for LEDs, buttons and signals

2, ~3, 4, ~5, ~6, 7, 8, ~9

Default pins in Arduino

I2C
SDA = A4, SCL = A5. Only these pins work with the Wire library defaults. I2C only works on A4 (SDA) and A5 (SCL); the SDA/SCL pins near AREF are the same signals.
SPI
MOSI = ~11, MISO = 12, SCK = 13, CS = ~10.
Analog inputs
A0, A1, A2, A3, A4, A5 (0–5 V)
