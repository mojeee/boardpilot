Questions

Which pins are I2C on the Arduino Uno R3?

SDA is A4 and SCL is A5 (the defaults of the Arduino Wire library). Only certain pins support I2C in hardware, so use these unless you know your core allows others.

Which Arduino Uno R3 pins should I avoid?

TX→1, RX←0 (USB serial link).

Is the Arduino Uno R3 5 V tolerant?

The Arduino Uno R3 runs at 5 V, so 5 V sensors connect directly. 3.3 V-only parts need a level shifter.

Which pins can read analog voltage on the Arduino Uno R3?

A0, A1, A2, A3, A4, A5, from 0 to 5 V.

How do I upload code to the Arduino Uno R3?

In the Arduino IDE pick the board arduino:avr:uno (core arduino:avr).
