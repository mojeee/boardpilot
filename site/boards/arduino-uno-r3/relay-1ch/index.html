Relay module with Arduino Uno R3

Wiring for the Relay module 1 channel (5 V) on the Arduino Uno R3 (ATmega328P, 5 V logic), chosen with the same pin rules BoardPilot uses: default buses first, and no pins that are used for flash, USB, the debugger or booting.

Wiring

Relay module pinRoleArduino Uno R3 pinNotes

Check before you power it on

  • Supply: 5 V from the 5V pin.
  • Motors, servos, relays and LED strips can draw more current than the Arduino Uno R3’s pins or USB can give. Power them separately and connect the grounds together.

Good to know

  • The relay coil needs 5 V: power the module from the 5 V pin, not 3V3. (Songle SRD-05VDC-SL-C datasheet, Coil voltage 5 V)

Test code (Arduino)

void setup() {
  pinMode(2, OUTPUT);  // IN on 2
}

void loop() {
  digitalWrite(2, HIGH);
  delay(500);
  digitalWrite(2, LOW);
  delay(500);
}

Arduino board: arduino:avr:uno.

Questions

Which Arduino Uno R3 pins do I use for the Relay module?

IN → 2 (PD2), GND → GND, VCC → 5V.

Does the Relay module work with the Arduino Uno R3 at 5 V?

Yes: the Relay module runs at 5 V and the Arduino Uno R3 uses 5 V signals, so no level shifting is needed.
