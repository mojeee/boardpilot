GPIO: pin in ingresso e in uscita

Accendi un LED, leggi un pulsante

GPIO significa ingresso/uscita di uso generale. Un pin configurato come uscita mette 3,3 V o 0 V sul filo. Un pin configurato come ingresso legge la tensione che arriva dall’esterno.

Demo interattiva

Un pin di uscita e un pin di ingresso. PA5 comanda un LED attraverso una resistenza; PC13 legge un pulsante con una pull-up. Inverti il bit di uscita per accendere il LED, premi il pulsante per vedere il bit di ingresso passare da 1 (rilasciato) a 0 (premuto), con il codice dei registri per ciascuno.

Provala dal vivo

La vera app, nel tuo browser: questa lezione con la sua anteprima 3D su una scheda ESP32 DevKit (30 pins) simulata. Niente da installare, niente da collegare.

Con una resistenza di pull-up il pin legge 1 quando nessuno tocca il pulsante. Premendolo il pin va a massa, quindi premuto legge 0. All’inizio sembra al contrario, ma è il modo standard di collegare un pulsante.

Tre passi per qualsiasi pin

  1. Accendi il clock della porta. Le periferiche partono spente per risparmiare energia; dimenticarlo è l’errore più comune dei principianti.
  2. Imposta la modalità del pin: ingresso, uscita, funzione alternativa (UART, I2C e altre) o analogico.
  3. Scrivi il registro di uscita, oppure leggi il registro di ingresso.
// NUCLEO-F401RE: green LED on PA5, blue button on PC13
RCC->AHB1ENR |= (1 << 0) | (1 << 2);   // 1. clock on for ports A and C
GPIOA->MODER &= ~(3 << (5 * 2));       // 2. PA5: clear its two mode bits
GPIOA->MODER |=  (1 << (5 * 2));       //    01 = output

while (1) {                            // 3. read the button, drive the LED
    if ((GPIOC->IDR & (1 << 13)) == 0) GPIOA->ODR |=  (1 << 5);
    else                               GPIOA->ODR &= ~(1 << 5);
}

Nei prodotti reali

I pulsanti veri rimbalzano: per qualche millisecondo il contatto oscilla tra 0 e 1. Filtralo via software (debounce), altrimenti una pressione conta come diverse.

In BoardPilot, Testa l’hardware legge e comanda i pin reali, e la scheda 3D mostra ogni pin che usi.
