Il C per l’embedded

Tipi a dimensione fissa, bit e volatile

In questa lezione

  1. Un registro è una fila di interruttori
  2. volatile: leggi l’hardware ogni volta
  3. Domande da colloquio

In un microcontrollore ogni registro ha una dimensione precisa, quindi il C embedded usa tipi con la dimensione nel nome.

#include <stdint.h>

uint8_t  a;   // 8 bits, 0..255       (a byte from a sensor)
uint16_t b;   // 16 bits, 0..65535    (an ADC reading)
uint32_t c;   // 32 bits              (a hardware register)
int16_t  t;   // signed 16 bits       (a temperature, can be negative)

Non usare mai un semplice int per l’hardware: la sua dimensione cambia da chip a chip.

Un registro è una fila di interruttori

Ogni bit di un registro controlla una cosa: un pin, una funzione, un flag. Il lavoro è quasi sempre cambiare un bit senza toccare gli altri. Provalo qui.

volatile: leggi l’hardware ogni volta

Il compilatore elimina le letture che ritiene inutili. L’hardware cambia i valori a sua insaputa, quindi i registri e le variabili condivise con gli interrupt devono essere volatile.

volatile uint32_t *status = (volatile uint32_t *)0x40011000;
while ((*status & (1 << 5)) == 0) { }   // wait for the "data ready" bit

Nei prodotti reali

Un volatile mancante è un bug classico: il codice funziona in debug e si blocca appena si attiva l’ottimizzazione.
