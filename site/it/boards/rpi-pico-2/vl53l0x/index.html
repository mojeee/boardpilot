VL53L0X con Raspberry Pi Pico 2

Collegamenti per VL53L0X time-of-flight distance su Raspberry Pi Pico 2 (RP2350, logica a 3,3 V), scelti con le stesse regole dei pin di BoardPilot: prima i bus predefiniti, e nessun pin usato per la flash, l’USB, il debugger o l’avvio.

Controlla prima di alimentare

  • Alimentazione: 3,3 V dal pin 3V3(OUT).
  • L’I2C usa i pin predefiniti della scheda GP4 (SDA) e GP5 (SCL). Quasi tutti i moduli hanno già le resistenze di pull-up; se il componente non viene trovato, controllale e prova a scambiare SDA e SCL.
  • Per essere sicuro che sia il chip originale, leggi il registro 0xC0: un componente originale risponde 0xEE.

Da sapere

  • Ogni sensore parte all’indirizzo 0x29. Per usarne due sullo stesso bus, tieni uno in reset con XSHUT e dai all’altro un nuovo indirizzo all’avvio; il nuovo indirizzo si perde allo spegnimento. (ST VL53L0X datasheet, I²C interface: device address 0x52 (8-bit), change of address)

Codice di prova (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = GP4, SCL = GP5 (the board's default I2C pins)
  Wire.beginTransmission(0x29);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "VL53L0X time-of-flight distance found at 0x29" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Scheda Arduino: rp2040:rp2040:rpipico2. Se la scheda non viene trovata, tieni premuto il pulsante BOOTSEL mentre colleghi il cavo USB.

Domande

Quali pin di Raspberry Pi Pico 2 uso per VL53L0X?

VIN → 3V3(OUT), GND → GND, SCL → GP5, SDA → GP4, XSHUT → GP15, GPIO1 → GP14.

VL53L0X funziona con Raspberry Pi Pico 2 a 3,3 V?

Sì: VL53L0X funziona a 3,3-5 V e Raspberry Pi Pico 2 usa segnali a 3,3 V, quindi non serve adattare i livelli.

Qual è l’indirizzo I2C di VL53L0X?

0x29. Una scansione I2C (BoardPilot la fa per te) mostra quale usa il tuo modulo.
