NEO-6M GPS con ESP32-S3-DevKitC-1

Collegamenti per NEO-6M GPS module (GY-NEO6MV2) su ESP32-S3-DevKitC-1 (ESP32-S3, logica a 3,3 V), scelti con le stesse regole dei pin di BoardPilot: prima i bus predefiniti, e nessun pin usato per la flash, l’USB, il debugger o l’avvio.

Collegamenti

Controlla prima di alimentare

  • Alimentazione: 3,3 V dal pin 3V3.

Da sapere

  • Il primo fix vuole la vista del cielo e richiede circa 30 secondi o più. Al chiuso potrebbe non trovarlo mai. (u-blox NEO-6 datasheet, Time-to-first-fix, cold start 27 s)
  • Comunica a 9600 baud. Collega il TX del modulo all’RX della scheda. (u-blox NEO-6 datasheet, UART default 9600 baud)

Codice di prova (Arduino)

HardwareSerial gps(1);

void setup() {
  Serial.begin(115200);
  gps.begin(9600, SERIAL_8N1, 5, 4);  // RX, TX
}

void loop() {
  while (gps.available()) Serial.write(gps.read());  // NMEA sentences, e.g. $GPGGA
}

Scheda Arduino: esp32:esp32:esp32s3. Usa la porta con la scritta UART. Se il caricamento non parte, tieni premuto BOOT, premi e rilascia RESET, poi rilascia BOOT.

Domande

Quali pin di ESP32-S3-DevKitC-1 uso per NEO-6M GPS?

VCC → 3V3, RX → 4, TX → 5, GND → G.

NEO-6M GPS funziona con ESP32-S3-DevKitC-1 a 3,3 V?

Sì: NEO-6M GPS funziona a 3,3-5 V e ESP32-S3-DevKitC-1 usa segnali a 3,3 V, quindi non serve adattare i livelli.

BoardPilot controlla questi collegamenti in 3D mentre li fai, e trova fili invertiti o mancanti sulla scheda reale.
