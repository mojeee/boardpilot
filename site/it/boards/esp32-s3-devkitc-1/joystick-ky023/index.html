Modulo joystick con ESP32-S3-DevKitC-1

Collegamenti per Analog joystick (KY-023) su ESP32-S3-DevKitC-1 (ESP32-S3, logica a 3,3 V), scelti con le stesse regole dei pin di BoardPilot: prima i bus predefiniti, e nessun pin usato per la flash, l’USB, il debugger o l’avvio.

Controlla prima di alimentare

  • Alimentazione: 3,3 V dal pin 3V3.

Codice di prova (Arduino)

void setup() {
  Serial.begin(115200);
}

void loop() {
  long mv = analogReadMilliVolts(1);  // VRX on 1
  Serial.println(mv);
  delay(200);
}

Scheda Arduino: esp32:esp32:esp32s3. Usa la porta con la scritta UART. Se il caricamento non parte, tieni premuto BOOT, premi e rilascia RESET, poi rilascia BOOT.

Domande

Quali pin di ESP32-S3-DevKitC-1 uso per Modulo joystick?

GND → G, +5V → 3V3, VRX → 1, VRY → 2, SW → 4.

Modulo joystick funziona con ESP32-S3-DevKitC-1 a 3,3 V?

Sì: Modulo joystick funziona a 3,3 V e ESP32-S3-DevKitC-1 usa segnali a 3,3 V, quindi non serve adattare i livelli.

BoardPilot controlla questi collegamenti in 3D mentre li fai, e trova fili invertiti o mancanti sulla scheda reale.
