DHT22 con Raspberry Pi Pico

Collegamenti per DHT22 (AM2302) temperature + humidity su Raspberry Pi Pico (RP2040, logica a 3,3 V), scelti con le stesse regole dei pin di BoardPilot: prima i bus predefiniti, e nessun pin usato per la flash, l’USB, il debugger o l’avvio.

Controlla prima di alimentare

  • Alimentazione: 3,3 V dal pin 3V3(OUT).

Da sapere

  • Leggilo al massimo una volta ogni 2 secondi. Letture più veloci restituiscono il valore vecchio o falliscono. (Aosong AM2302 datasheet, Collecting period 2 s)

Codice di prova (Arduino)

// Library: DHT sensor library (Adafruit)
#include <DHT.h>

DHT dht(15, DHT22);

void setup() {
  Serial.begin(115200);
  dht.begin();
}

void loop() {
  delay(2000);  // the DHT22 needs 2 s between readings
  Serial.print(dht.readTemperature());
  Serial.print(" C  ");
  Serial.print(dht.readHumidity());
  Serial.println(" %");
}

Scheda Arduino: rp2040:rp2040:rpipico. Se la scheda non viene trovata, tieni premuto il pulsante BOOTSEL mentre colleghi il cavo USB.

Domande

Quali pin di Raspberry Pi Pico uso per DHT22?

VCC → 3V3(OUT), DATA → GP15, GND → GND.

DHT22 funziona con Raspberry Pi Pico a 3,3 V?

Sì: DHT22 funziona a 3,3-5 V e Raspberry Pi Pico usa segnali a 3,3 V, quindi non serve adattare i livelli.

BoardPilot controlla questi collegamenti in 3D mentre li fai, e trova fili invertiti o mancanti sulla scheda reale.
