Motore passo-passo 28BYJ-48 con Raspberry Pi Pico

Collegamenti per 28BYJ-48 stepper + ULN2003 driver su Raspberry Pi Pico (RP2040, logica a 3,3 V), scelti con le stesse regole dei pin di BoardPilot: prima i bus predefiniti, e nessun pin usato per la flash, l’USB, il debugger o l’avvio.

Controlla prima di alimentare

  • Alimentazione: 5 V dal pin VBUS.
  • Motori, servo, relè e strisce LED possono assorbire più corrente di quella che i pin o l’USB di Raspberry Pi Pico possono dare. Alimentali a parte e collega insieme le masse.

Da sapere

  • Ogni bobina assorbe circa 100 mA a 5 V (50 Ω). Alimenta la scheda ULN2003 dai 5 V, mai da un pin GPIO. (28BYJ-48 stepper motor datasheet, Rated voltage 5 V, DC resistance 50 Ω per phase)

Codice di prova (Arduino)

// Library: Stepper (built in)
#include <Stepper.h>

// 2048 steps per turn; note the IN1, IN3, IN2, IN4 order for this motor
Stepper motor(2048, 15, 13, 14, 12);

void setup() {
  motor.setSpeed(10);  // rpm
}

void loop() {
  motor.step(2048);   // one turn
  delay(500);
  motor.step(-2048);  // and back
  delay(500);
}

Scheda Arduino: rp2040:rp2040:rpipico. Se la scheda non viene trovata, tieni premuto il pulsante BOOTSEL mentre colleghi il cavo USB.

Domande

Quali pin di Raspberry Pi Pico uso per Motore passo-passo 28BYJ-48?

IN1 → GP15, IN2 → GP14, IN3 → GP13, IN4 → GP12, - → GND, + → VBUS.

Motore passo-passo 28BYJ-48 funziona con Raspberry Pi Pico a 3,3 V?

Sì: Motore passo-passo 28BYJ-48 funziona a 5 V e Raspberry Pi Pico usa segnali a 3,3 V, quindi non serve adattare i livelli.
