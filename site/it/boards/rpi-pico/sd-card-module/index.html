Modulo scheda SD con Raspberry Pi Pico

Collegamenti per SD card module (full size, SPI) su Raspberry Pi Pico (RP2040, logica a 3,3 V), scelti con le stesse regole dei pin di BoardPilot: prima i bus predefiniti, e nessun pin usato per la flash, l’USB, il debugger o l’avvio.

Controlla prima di alimentare

  • Alimentazione: 3,3 V dal pin 3V3(OUT).

Da sapere

  • La libreria SD legge schede FAT16 e FAT32. Le schede formattate exFAT (quasi tutte sopra i 32 GB) non vengono trovate. (Arduino SD library reference, Supported file systems: FAT16 and FAT32)

Codice di prova (Arduino)

// Library: SD (built in)
#include <SPI.h>
#include <SD.h>

void setup() {
  Serial.begin(115200);
  if (!SD.begin(17)) {
    Serial.println("No card: check wiring, the card format (FAT32) and power");
    return;
  }
  File f = SD.open("/test.txt", FILE_WRITE);
  f.println("Hello from the board");
  f.close();
  Serial.println("Wrote test.txt");
}

void loop() {}

Scheda Arduino: rp2040:rp2040:rpipico. Se la scheda non viene trovata, tieni premuto il pulsante BOOTSEL mentre colleghi il cavo USB.

Domande

Quali pin di Raspberry Pi Pico uso per Modulo scheda SD?

GND → GND, 3V3 → 3V3(OUT), CS → GP17, MOSI → GP19, SCK → GP18, MISO → GP16, GND2 → GND.

Modulo scheda SD funziona con Raspberry Pi Pico a 3,3 V?

Sì: Modulo scheda SD funziona a 3,3-5 V e Raspberry Pi Pico usa segnali a 3,3 V, quindi non serve adattare i livelli.

BoardPilot controlla questi collegamenti in 3D mentre li fai, e trova fili invertiti o mancanti sulla scheda reale.
