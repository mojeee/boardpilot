Modulo joystick con Teensy 4.1

Collegamenti per Analog joystick (KY-023) su Teensy 4.1 (MIMXRT1062DVJ6B, logica a 3,3 V), scelti con le stesse regole dei pin di BoardPilot: prima i bus predefiniti, e nessun pin usato per la flash, l’USB, il debugger o l’avvio.

Controlla prima di alimentare

  • Alimentazione: 3,3 V dal pin 3V.

Codice di prova (Arduino)

void setup() {
  Serial.begin(115200);
  analogReadResolution(12);
}

void loop() {
  long mv = (long)analogRead(14) * 3300L / 4095;  // VRX on 14
  Serial.println(mv);
  delay(200);
}

Scheda Arduino: teensy:avr:teensy41. Premi una volta il pulsante bianco di programmazione se il caricamento aspetta la scheda.

Domande

Quali pin di Teensy 4.1 uso per Modulo joystick?

GND → G, +5V → 3V, VRX → 14 (GPIO_AD_B1_02), VRY → 15 (GPIO_AD_B1_03), SW → 2 (GPIO_EMC_04).

Modulo joystick funziona con Teensy 4.1 a 3,3 V?

Sì: Modulo joystick funziona a 3,3 V e Teensy 4.1 usa segnali a 3,3 V, quindi non serve adattare i livelli.

BoardPilot controlla questi collegamenti in 3D mentre li fai, e trova fili invertiti o mancanti sulla scheda reale.
