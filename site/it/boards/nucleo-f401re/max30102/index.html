MAX30102 con NUCLEO-F401RE

Collegamenti per MAX30102 heart rate + SpO2 su NUCLEO-F401RE (STM32F401RE, logica a 3,3 V), scelti con le stesse regole dei pin di BoardPilot: prima i bus predefiniti, e nessun pin usato per la flash, l’USB, il debugger o l’avvio.

Controlla prima di alimentare

  • Alimentazione: 3,3 V dal pin 3V3.
  • L’I2C usa i pin predefiniti della scheda SDA/D14 (SDA) e SCL/D15 (SCL). Quasi tutti i moduli hanno già le resistenze di pull-up; se il componente non viene trovato, controllale e prova a scambiare SDA e SCL.
  • Per essere sicuro che sia il chip originale, leggi il registro 0xFF: un componente originale risponde 0x15.

Codice di prova (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = SDA/D14, SCL = SCL/D15 (the board's default I2C pins)
  Wire.beginTransmission(0x57);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "MAX30102 heart rate + SpO2 found at 0x57" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Scheda Arduino: STMicroelectronics:stm32:Nucleo_64:pnum=NUCLEO_F401RE. Collega il cavo USB alla porta mini-USB sul lato dell’ST-LINK. Non serve premere nessun pulsante.

Domande

Quali pin di NUCLEO-F401RE uso per MAX30102?

VIN → 3V3, SDA → SDA/D14 (PB9), SCL → SCL/D15 (PB8), INT → D2 (PA10), GND → GND.

MAX30102 funziona con NUCLEO-F401RE a 3,3 V?

Sì: MAX30102 funziona a 3,3-5 V e NUCLEO-F401RE usa segnali a 3,3 V, quindi non serve adattare i livelli.

Qual è l’indirizzo I2C di MAX30102?

0x57. Una scansione I2C (BoardPilot la fa per te) mostra quale usa il tuo modulo.
