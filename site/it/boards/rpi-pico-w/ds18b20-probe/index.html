DS18B20 con Raspberry Pi Pico W

Collegamenti per DS18B20 waterproof temperature probe su Raspberry Pi Pico W (RP2040, logica a 3,3 V), scelti con le stesse regole dei pin di BoardPilot: prima i bus predefiniti, e nessun pin usato per la flash, l’USB, il debugger o l’avvio.

Controlla prima di alimentare

  • Alimentazione: 3,3 V dal pin 3V3(OUT).

Codice di prova (Arduino)

// Library: OneWire, DallasTemperature
#include <OneWire.h>
#include <DallasTemperature.h>

OneWire bus(15);  // needs a 4.7 kΩ pull-up from DQ to VDD
DallasTemperature sensors(&bus);

void setup() {
  Serial.begin(115200);
  sensors.begin();
  Serial.print("Sensors found: ");
  Serial.println(sensors.getDeviceCount());
}

void loop() {
  sensors.requestTemperatures();
  Serial.println(sensors.getTempCByIndex(0));
  delay(1000);
}

Scheda Arduino: rp2040:rp2040:rpipicow. Se la scheda non viene trovata, tieni premuto il pulsante BOOTSEL mentre colleghi il cavo USB.

Domande

Quali pin di Raspberry Pi Pico W uso per DS18B20?

VDD → 3V3(OUT), DQ → GP15, GND → GND.

DS18B20 funziona con Raspberry Pi Pico W a 3,3 V?

Sì: DS18B20 funziona a 3,3-5 V e Raspberry Pi Pico W usa segnali a 3,3 V, quindi non serve adattare i livelli.

BoardPilot controlla questi collegamenti in 3D mentre li fai, e trova fili invertiti o mancanti sulla scheda reale.
