MPU6050 con Raspberry Pi Pico W

Collegamenti per MPU6050 (GY-521) accelerometer + gyro su Raspberry Pi Pico W (RP2040, logica a 3,3 V), scelti con le stesse regole dei pin di BoardPilot: prima i bus predefiniti, e nessun pin usato per la flash, l’USB, il debugger o l’avvio.

Controlla prima di alimentare

  • Alimentazione: 3,3 V dal pin 3V3(OUT).
  • L’I2C usa i pin predefiniti della scheda GP4 (SDA) e GP5 (SCL). Quasi tutti i moduli hanno già le resistenze di pull-up; se il componente non viene trovato, controllale e prova a scambiare SDA e SCL.
  • Per essere sicuro che sia il chip originale, leggi il registro 0x75: un componente originale risponde 0x68.

Da sapere

  • L’indirizzo è 0x68, oppure 0x69 con AD0 alto. (InvenSense MPU-6000/MPU-6050 Product Specification, I²C interface: slave address)
  • Parte in modalità sleep e legge zeri finché PWR_MGMT_1 (0x6B) non viene azzerato. Le librerie lo fanno in begin(); anche il tuo codice deve farlo. (InvenSense MPU-6000/MPU-6050 Register Map, Register 107, Power Management 1 (reset value 0x40, sleep))

Codice di prova (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = GP4, SCL = GP5 (the board's default I2C pins)
  Wire.beginTransmission(0x68);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "MPU6050 (GY-521) accelerometer + gyro found at 0x68" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Scheda Arduino: rp2040:rp2040:rpipicow. Se la scheda non viene trovata, tieni premuto il pulsante BOOTSEL mentre colleghi il cavo USB.

Domande

Quali pin di Raspberry Pi Pico W uso per MPU6050?

VCC → 3V3(OUT), GND → GND, SCL → GP5, SDA → GP4, INT → GP15.

MPU6050 funziona con Raspberry Pi Pico W a 3,3 V?

Sì: MPU6050 funziona a 3,3-5 V e Raspberry Pi Pico W usa segnali a 3,3 V, quindi non serve adattare i livelli.

Qual è l’indirizzo I2C di MPU6050?

0x68 o 0x69. Una scansione I2C (BoardPilot la fa per te) mostra quale usa il tuo modulo.
