SSD1306 OLED con WeAct Black Pill STM32F411CE

Collegamenti per SSD1306 OLED 128x64 (I2C) su WeAct Black Pill STM32F411CE (STM32F411CE, logica a 3,3 V), scelti con le stesse regole dei pin di BoardPilot: prima i bus predefiniti, e nessun pin usato per la flash, l’USB, il debugger o l’avvio.

Controlla prima di alimentare

  • Alimentazione: 3,3 V dal pin 3V3.
  • L’I2C usa i pin predefiniti della scheda B7 (SDA) e B6 (SCL). Quasi tutti i moduli hanno già le resistenze di pull-up; se il componente non viene trovato, controllale e prova a scambiare SDA e SCL.

Da sapere

  • L’indirizzo è 0x3C o 0x3D (il ponticello sul retro). Una scheda con scritto “0x78” è a 0x3C: la scritta mostra l’indirizzo spostato a sinistra di un bit. (Solomon Systech SSD1306 datasheet, I²C-bus interface: slave address, SA0 bit)

Codice di prova (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = B7, SCL = B6 (the board's default I2C pins)
  Wire.beginTransmission(0x3C);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "SSD1306 OLED 128x64 (I2C) found at 0x3C" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Scheda Arduino: STMicroelectronics:stm32:GenF4:pnum=BLACKPILL_F411CE,usb=CDCgen,upload_method=dfuMethod. Per caricare via USB, tieni premuto BOOT0, premi e rilascia NRST, poi rilascia BOOT0 (modalità DFU). Funziona anche un ST-LINK sui pin SWD.

Domande

Quali pin di WeAct Black Pill STM32F411CE uso per SSD1306 OLED?

GND → G, VCC → 3V3, SCL → B6 (PB6), SDA → B7 (PB7).

SSD1306 OLED funziona con WeAct Black Pill STM32F411CE a 3,3 V?

Sì: SSD1306 OLED funziona a 3,3-5 V e WeAct Black Pill STM32F411CE usa segnali a 3,3 V, quindi non serve adattare i livelli.

Qual è l’indirizzo I2C di SSD1306 OLED?

0x3C o 0x3D. Una scansione I2C (BoardPilot la fa per te) mostra quale usa il tuo modulo.
