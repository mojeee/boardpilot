VL53L0X con WeAct Black Pill STM32F411CE

Collegamenti per VL53L0X time-of-flight distance su WeAct Black Pill STM32F411CE (STM32F411CE, logica a 3,3 V), scelti con le stesse regole dei pin di BoardPilot: prima i bus predefiniti, e nessun pin usato per la flash, l’USB, il debugger o l’avvio.

Controlla prima di alimentare

  • Alimentazione: 3,3 V dal pin 3V3.
  • L’I2C usa i pin predefiniti della scheda B7 (SDA) e B6 (SCL). Quasi tutti i moduli hanno già le resistenze di pull-up; se il componente non viene trovato, controllale e prova a scambiare SDA e SCL.
  • Per essere sicuro che sia il chip originale, leggi il registro 0xC0: un componente originale risponde 0xEE.

Codice di prova (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin();  // SDA = B7, SCL = B6 (the board's default I2C pins)
  Wire.beginTransmission(0x29);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "VL53L0X time-of-flight distance found at 0x29" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}

Scheda Arduino: STMicroelectronics:stm32:GenF4:pnum=BLACKPILL_F411CE,usb=CDCgen,upload_method=dfuMethod. Per caricare via USB, tieni premuto BOOT0, premi e rilascia NRST, poi rilascia BOOT0 (modalità DFU). Funziona anche un ST-LINK sui pin SWD.

Domande

Quali pin di WeAct Black Pill STM32F411CE uso per VL53L0X?

VIN → 3V3, GND → G, SCL → B6 (PB6), SDA → B7 (PB7), XSHUT → B12 (PB12), GPIO1 → A0 (PA0).

VL53L0X funziona con WeAct Black Pill STM32F411CE a 3,3 V?

Sì: VL53L0X funziona a 3,3-5 V e WeAct Black Pill STM32F411CE usa segnali a 3,3 V, quindi non serve adattare i livelli.

Qual è l’indirizzo I2C di VL53L0X?

0x29. Una scansione I2C (BoardPilot la fa per te) mostra quale usa il tuo modulo.
