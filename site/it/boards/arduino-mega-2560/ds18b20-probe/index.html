DS18B20 con Arduino Mega 2560 R3

Collegamenti per DS18B20 waterproof temperature probe su Arduino Mega 2560 R3 (ATmega2560, logica a 5 V), scelti con le stesse regole dei pin di BoardPilot: prima i bus predefiniti, e nessun pin usato per la flash, l’USB, il debugger o l’avvio.

Collegamenti

Pin di DS18B20RuoloPin di Arduino Mega 2560 R3Note
VDDAlimentazione5V
DQDati one-wire22 (PA0)
GNDMassaGND

Controlla prima di alimentare

  • Alimentazione: 5 V dal pin 5V.

Da sapere

  • Vuole una resistenza di pull-up da 4,7 kΩ tra DATA e VCC. Senza, il sensore non viene trovato. (Maxim DS18B20 datasheet, Powering the DS18B20; 1-Wire bus pull-up)
  • Una lettura a 12 bit richiede fino a 750 ms. Il codice che aspetta meno riceve il valore precedente, oppure 85 °C (il valore all’accensione). (Maxim DS18B20 datasheet, Temperature conversion time 750 ms max; power-on reset value +85 °C)

Codice di prova (Arduino)

// Library: OneWire, DallasTemperature
#include <OneWire.h>
#include <DallasTemperature.h>

OneWire bus(22);  // needs a 4.7 kΩ pull-up from DQ to VDD
DallasTemperature sensors(&bus);

void setup() {
  Serial.begin(115200);
  sensors.begin();
  Serial.print("Sensors found: ");
  Serial.println(sensors.getDeviceCount());
}

void loop() {
  sensors.requestTemperatures();
  Serial.println(sensors.getTempCByIndex(0));
  delay(1000);
}

Scheda Arduino: arduino:avr:mega.

Domande

Quali pin di Arduino Mega 2560 R3 uso per DS18B20?

VDD → 5V, DQ → 22 (PA0), GND → GND.

DS18B20 funziona con Arduino Mega 2560 R3 a 5 V?

Sì: DS18B20 funziona a 3,3-5 V e Arduino Mega 2560 R3 usa segnali a 5 V, quindi non serve adattare i livelli.
