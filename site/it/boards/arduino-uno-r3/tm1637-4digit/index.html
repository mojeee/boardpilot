TM1637 con Arduino Uno R3

Collegamenti per TM1637 4-digit 7-segment display su Arduino Uno R3 (ATmega328P, logica a 5 V), scelti con le stesse regole dei pin di BoardPilot: prima i bus predefiniti, e nessun pin usato per la flash, l’USB, il debugger o l’avvio.

Controlla prima di alimentare

  • Alimentazione: 5 V dal pin 5V.

Da sapere

  • CLK e DIO non sono I2C: usa una libreria TM1637. Vanno bene due pin qualsiasi. (Titan Micro TM1637 datasheet, Two-wire serial interface)

Codice di prova (Arduino)

// Library: TM1637 (Avishay Orpaz)
#include <TM1637Display.h>

TM1637Display display(2, 3);  // CLK, DIO

void setup() {
  display.setBrightness(4);
}

void loop() {
  display.showNumberDec(millis() / 1000);  // seconds since start
  delay(200);
}

Scheda Arduino: arduino:avr:uno.

Domande

Quali pin di Arduino Uno R3 uso per TM1637?

CLK → 2 (PD2), DIO → ~3 (PD3), GND → GND, 5V → 5V.

TM1637 funziona con Arduino Uno R3 a 5 V?

Sì: TM1637 funziona a 3,3-5 V e Arduino Uno R3 usa segnali a 5 V, quindi non serve adattare i livelli.

BoardPilot controlla questi collegamenti in 3D mentre li fai, e trova fili invertiti o mancanti sulla scheda reale.
