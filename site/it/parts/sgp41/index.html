SGP41 VOC + NOx sensor con ESP32

Alimentazione 3.3 V Bus I2C Indirizzo I2C 0x59 Misura VOC, NOx

Pin e collegamento all’ESP32

PinRuoloPin ESP32Note
VCCAlimentazione3V3Chip supply 1.7 to 3.6 V: use 3V3
GNDMassaGND
SCLClock I2C (SCL)D22
SDADati I2C (SDA)D21

Collegamento consigliato per l’ESP32 DevKit a 30 pin, evitando i pin della flash, di sola lettura e di strapping. BoardPilot lo controlla mentre colleghi.

Codice di partenza (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);  // SDA = GPIO 21, SCL = GPIO 22
  Wire.beginTransmission(0x59);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "SGP41 VOC + NOx sensor found at 0x59" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}
