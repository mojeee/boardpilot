Capacitive soil moisture sensor v1.2 con ESP32

Alimentazione 3.3-5 V Bus ANALOG Misura umidità del terreno

Pin e collegamento all’ESP32

PinRuoloPin ESP32Note
GNDMassaGND
VCCAlimentazione3V3
AOUTUscita analogicaD34Lower voltage means wetter soil. To an ADC pin (prefer ADC1: GPIO 32 to 39)

Collegamento consigliato per l’ESP32 DevKit a 30 pin, evitando i pin della flash, di sola lettura e di strapping. BoardPilot lo controlla mentre colleghi.

Codice di partenza (Arduino)

void setup() { Serial.begin(115200); }

void loop() {
  int mv = analogReadMilliVolts(34);  // AOUT on GPIO 34
  Serial.println(mv);
  delay(200);
}
