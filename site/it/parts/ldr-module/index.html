Light sensor module (LDR + LM393) con ESP32

Alimentazione 3.3-5 V Bus ANALOG Misura luce

Pin e collegamento all’ESP32

PinRuoloPin ESP32Note
VCCAlimentazione3V3Use 3V3 so AO stays within the ADC range
GNDMassaGND
DOUscita (la pilota il componente)D25HIGH/LOW when light crosses the threshold set with the trimmer
AOUscita analogicaD34To an ADC pin (prefer ADC1: GPIO 32 to 39)

Collegamento consigliato per l’ESP32 DevKit a 30 pin, evitando i pin della flash, di sola lettura e di strapping. BoardPilot lo controlla mentre colleghi.

Codice di partenza (Arduino)

void setup() { Serial.begin(115200); }

void loop() {
  int mv = analogReadMilliVolts(34);  // AO on GPIO 34
  Serial.println(mv);
  delay(200);
}
