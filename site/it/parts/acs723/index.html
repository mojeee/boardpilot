ACS723 current sensor module con ESP32

Alimentazione 5 V Bus ANALOG Misura corrente

Pin e collegamento all’ESP32

PinRuoloPin ESP32Note
VCCAlimentazioneVINNeeds 5 V: use VIN
GNDMassaGND
OUTUscita analogicaD34Bidirectional versions sit at 2.5 V at 0 A and can reach 5 V: use a divider before the ADC
IP+Non collegato all’ESP32—Current path in. Never wire to the ESP32
IP-Non collegato all’ESP32—Current path out

Collegamento consigliato per l’ESP32 DevKit a 30 pin, evitando i pin della flash, di sola lettura e di strapping. BoardPilot lo controlla mentre colleghi.

Questo modulo è venduto per 5 V. Le sue uscite possono essere a 5 V: usa un traslatore di livello o un partitore sugli ingressi dell’ESP32.

Codice di partenza (Arduino)

void setup() { Serial.begin(115200); }

void loop() {
  int mv = analogReadMilliVolts(34);  // OUT on GPIO 34
  Serial.println(mv);
  delay(200);
}
