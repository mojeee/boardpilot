MQ-6 LPG sensor con ESP32

Alimentazione 5 V Bus ANALOG Misura GPL, gas

Pin e collegamento all’ESP32

PinRuoloPin ESP32Note
VCCAlimentazioneVINNeeds 5 V for the heater (about 150 mA): use VIN
GNDMassaGND
DOUscita (la pilota il componente)D25Threshold output. Its HIGH level is 5 V: use a voltage divider
AOUscita analogicaD34Can reach 5 V: use a voltage divider before the ADC

Collegamento consigliato per l’ESP32 DevKit a 30 pin, evitando i pin della flash, di sola lettura e di strapping. BoardPilot lo controlla mentre colleghi.

Questo modulo è venduto per 5 V. Le sue uscite possono essere a 5 V: usa un traslatore di livello o un partitore sugli ingressi dell’ESP32.

Codice di partenza (Arduino)

void setup() { Serial.begin(115200); }

void loop() {
  int mv = analogReadMilliVolts(34);  // AO on GPIO 34
  Serial.println(mv);
  delay(200);
}
