UDA1334A I2S stereo DAC con ESP32

Alimentazione 3.3-5 V Bus GPIO

Pin e collegamento all’ESP32

PinRuoloPin ESP32Note
VINAlimentazione3V3Pin order varies between boards: match by the printed label. 3.3 V or 5 V
3VONon collegato all’ESP32—3.3 V output of the regulator. Leave unconnected
GNDMassaGND
WSELChip select SPID25I2S word select (LRC), not SPI
DINIngresso (lo pilota l’ESP32)D26I2S audio data from the ESP32
BCLKClock SPID27I2S bit clock, not SPI
LOUTNon collegato all’ESP32—Line out left (or use the headphone jack)
AGNDNon collegato all’ESP32—Audio ground for the line outputs
ROUTNon collegato all’ESP32—Line out right

Collegamento consigliato per l’ESP32 DevKit a 30 pin, evitando i pin della flash, di sola lettura e di strapping. BoardPilot lo controlla mentre colleghi.

Codice di partenza (Arduino)

void setup() { pinMode(26, OUTPUT); }  // DIN

void loop() {
  digitalWrite(26, HIGH);
  delay(500);
  digitalWrite(26, LOW);
  delay(500);
}
