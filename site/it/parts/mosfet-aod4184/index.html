MOSFET switch module (dual AOD4184) con ESP32

Alimentazione 3.3-5 V Bus GPIO

Pin e collegamento all’ESP32

PinRuoloPin ESP32Note
PWMIngresso (lo pilota l’ESP32)D25Pin order varies between boards: match by the printed label. Trigger / PWM. HIGH = load on
GNDMassaGND
VIN+Non collegato all’ESP32—Load supply + 5 to 36 V
VIN-Non collegato all’ESP32—Load supply -
OUT+Non collegato all’ESP32—To the load +
OUT-Non collegato all’ESP32—To the load -. Add a flyback diode for motors and coils

Collegamento consigliato per l’ESP32 DevKit a 30 pin, evitando i pin della flash, di sola lettura e di strapping. BoardPilot lo controlla mentre colleghi.

Codice di partenza (Arduino)

void setup() { pinMode(25, OUTPUT); }  // PWM

void loop() {
  digitalWrite(25, HIGH);
  delay(500);
  digitalWrite(25, LOW);
  delay(500);
}
