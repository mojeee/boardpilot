BNO085 / BNO08x 9-axis orientation sensor con ESP32

Alimentazione 3.3-5 V Bus I2C Indirizzo I2C 0x4A / 0x4B Misura orientamento, accelerazione, rotazione, campo magnetico

Pin e collegamento all’ESP32

PinRuoloPin ESP32Note
VINAlimentazione3V3Adafruit-style pin order. Other BNO08x boards differ: check the silkscreen
3VONon collegato all’ESP32—Output of the on-board 3.3 V regulator. Leave unconnected
GNDMassaGND
SCLClock I2C (SCL)D22
SDADati I2C (SDA)D21
INTInterruptD35LOW when the sensor has data. Recommended
RSTIngresso (lo pilota l’ESP32)D25Reset, active LOW. Recommended
CSNon collegato all’ESP32—SPI chip select. Leave unconnected or HIGH for I2C
DINon collegato all’ESP32—SPI data in / address select in I2C mode. Leave unconnected for 0x4A
P0Non collegato all’ESP32—Protocol select. Leave LOW for I2C
P1Non collegato all’ESP32—Protocol select. Leave LOW for I2C
BTNon collegato all’ESP32—Boot pin. Leave unconnected

Collegamento consigliato per l’ESP32 DevKit a 30 pin, evitando i pin della flash, di sola lettura e di strapping. BoardPilot lo controlla mentre colleghi.

Codice di partenza (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);  // SDA = GPIO 21, SCL = GPIO 22
  Wire.beginTransmission(0x4A);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "BNO085 / BNO08x 9-axis orientation sensor found at 0x4A" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}
