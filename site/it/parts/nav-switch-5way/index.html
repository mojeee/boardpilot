5-way navigation button module con ESP32

Alimentazione 3.3 V Bus GPIO

Pin e collegamento all’ESP32

PinRuoloPin ESP32Note
COMMassaGNDCommon: to GND. Keys read LOW with INPUT_PULLUP
UPUscita (la pilota il componente)D25Up
DWNUscita (la pilota il componente)D26Down
LFTUscita (la pilota il componente)D27Left
RHTUscita (la pilota il componente)D32Right
MIDUscita (la pilota il componente)D33Centre press
SETUscita (la pilota il componente)D23Extra SET button
RSTUscita (la pilota il componente)D19Extra RST button (not the ESP32 reset)

Collegamento consigliato per l’ESP32 DevKit a 30 pin, evitando i pin della flash, di sola lettura e di strapping. BoardPilot lo controlla mentre colleghi.

Codice di partenza (Arduino)

void setup() {
  Serial.begin(115200);
  pinMode(25, INPUT);  // UP
}

void loop() {
  Serial.println(digitalRead(25));
  delay(100);
}
