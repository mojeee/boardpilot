BTS7960 43 A motor driver (IBT-2) con ESP32

Alimentazione 5 V Bus GPIO

Pin e collegamento all’ESP32

PinRuoloPin ESP32Note
RPWMIngresso (lo pilota l’ESP32)D25Forward PWM
LPWMIngresso (lo pilota l’ESP32)D26Reverse PWM
R_ENIngresso (lo pilota l’ESP32)D27HIGH to enable. Often tied to L_EN
L_ENIngresso (lo pilota l’ESP32)D32HIGH to enable
R_ISUscita analogicaD34Current sense. Can exceed 3.3 V on a fault: add a divider before an ADC pin
L_ISUscita analogicaD35Current sense. Can exceed 3.3 V on a fault: add a divider before an ADC pin
VCCAlimentazioneVIN5 V logic supply: use VIN. Inputs via a 74HC244 buffer: 3.3 V is below spec, often works
GNDMassaGND
B+Non collegato all’ESP32—Motor supply + 6 to 27 V (screw terminal)
B-Non collegato all’ESP32—Motor supply - (screw terminal)
M+Non collegato all’ESP32—Motor
M-Non collegato all’ESP32—Motor

Collegamento consigliato per l’ESP32 DevKit a 30 pin, evitando i pin della flash, di sola lettura e di strapping. BoardPilot lo controlla mentre colleghi.

Questo modulo è venduto per 5 V. Le sue uscite possono essere a 5 V: usa un traslatore di livello o un partitore sugli ingressi dell’ESP32.

Codice di partenza (Arduino)

void setup() { Serial.begin(115200); }

void loop() {
  int mv = analogReadMilliVolts(34);  // R_IS on GPIO 34
  Serial.println(mv);
  delay(200);
}
