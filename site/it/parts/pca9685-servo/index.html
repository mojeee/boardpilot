Pin e collegamento all’ESP32

PinRuoloPin ESP32Note
GNDMassaGND
OEIngresso (lo pilota l’ESP32)D25Output enable, active LOW. Leave unconnected (pulled LOW)
SCLClock I2C (SCL)D22
SDADati I2C (SDA)D21
VCCAlimentazione3V3Logic supply: 3V3
V+Non collegato all’ESP32—Servo power from a separate 5 to 6 V supply. Never the logic pin

Collegamento consigliato per l’ESP32 DevKit a 30 pin, evitando i pin della flash, di sola lettura e di strapping. BoardPilot lo controlla mentre colleghi.

Codice di partenza (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);  // SDA = GPIO 21, SCL = GPIO 22
  Wire.beginTransmission(0x40);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "PCA9685 16-channel PWM / servo driver found at 0x40" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}
