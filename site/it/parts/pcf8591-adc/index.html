PCF8591 ADC/DAC module (YL-40) con ESP32

Alimentazione 3.3-5 V Bus I2C Indirizzo I2C 0x48 / 0x49 / 0x4A / 0x4B / 0x4C / 0x4D / 0x4E / 0x4F Misura tensione

Collegamento consigliato per l’ESP32 DevKit a 30 pin, evitando i pin della flash, di sola lettura e di strapping. BoardPilot lo controlla mentre colleghi.

Codice di partenza (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);  // SDA = GPIO 21, SCL = GPIO 22
  Wire.beginTransmission(0x48);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "PCF8591 ADC/DAC module (YL-40) found at 0x48" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}
