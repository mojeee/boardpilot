Sensirion SEN55 environmental node with ESP32

Supply 5 V Bus I2C I2C address 0x69 Measures particulates, voc, nox, temperature, humidity

Pins and ESP32 wiring

PinRoleESP32 pinNotes
VDDPowerVINPin 1. Needs 5 V for the fan: use VIN
GNDGroundGNDPin 2
SDAI2C data (SDA)D21Pin 3. Add a pull-up to 3.3 V
SCLI2C clock (SCL)D22Pin 4. Add a pull-up to 3.3 V
SELNot wired to the ESP32—Pin 5. Connect to GND for I2C
NCNot wired to the ESP32—Pin 6. Not connected

Suggested wiring for the 30-pin ESP32 DevKit, avoiding flash, input-only and strapping pins. BoardPilot checks it for you as you wire.

This module is sold for 5 V. Its outputs may be 5 V: use a level shifter or a voltage divider on ESP32 inputs.

Starter code (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);  // SDA = GPIO 21, SCL = GPIO 22
  Wire.beginTransmission(0x69);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "Sensirion SEN55 environmental node found at 0x69" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}
