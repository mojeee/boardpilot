INA3221 3-channel current + voltage monitor with ESP32

Supply 3.3-5 V Bus I2C I2C address 0x40 / 0x41 / 0x42 / 0x43 Measures current, voltage, power

Suggested wiring for the 30-pin ESP32 DevKit, avoiding flash, input-only and strapping pins. BoardPilot checks it for you as you wire.

Starter code (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);  // SDA = GPIO 21, SCL = GPIO 22
  Wire.beginTransmission(0x40);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "INA3221 3-channel current + voltage monitor found at 0x40" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}
