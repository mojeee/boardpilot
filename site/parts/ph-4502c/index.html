PH-4502C pH sensor module with ESP32

Supply 5 V Bus ANALOG Measures ph

Pins and ESP32 wiring

PinRoleESP32 pinNotes
TOAnalog outputD34Board temperature (not the liquid), optional
DOOutput (the part drives it)D25Threshold output, set by a trimmer. Its HIGH level is 5 V: use a voltage divider
POAnalog outputD35pH voltage, about 2.5 V at pH 7 after calibration, up to 5 V: use a voltage divider
GND1GroundGNDFirst G pin
GND2GroundGNDSecond G pin
VCCPowerVINMarked V+. Needs 5 V: use VIN

Suggested wiring for the 30-pin ESP32 DevKit, avoiding flash, input-only and strapping pins. BoardPilot checks it for you as you wire.

This module is sold for 5 V. Its outputs may be 5 V: use a level shifter or a voltage divider on ESP32 inputs.

Starter code (Arduino)

void setup() { Serial.begin(115200); }

void loop() {
  int mv = analogReadMilliVolts(34);  // TO on GPIO 34
  Serial.println(mv);
  delay(200);
}
