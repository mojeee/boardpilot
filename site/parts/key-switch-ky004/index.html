Button module (KY-004) with ESP32

Supply 3.3-5 V Bus GPIO

Pins and ESP32 wiring

PinRoleESP32 pinNotes
SOutput (the part drives it)D25Signal: to a GPIO. Use INPUT_PULLUP too
VCCPower3V3Middle pin
GNDGroundGNDMarked - on the board

Suggested wiring for the 30-pin ESP32 DevKit, avoiding flash, input-only and strapping pins. BoardPilot checks it for you as you wire.

Starter code (Arduino)

void setup() {
  Serial.begin(115200);
  pinMode(25, INPUT);  // S
}

void loop() {
  Serial.println(digitalRead(25));
  delay(100);
}
