INA219 current + voltage monitor with ESP32

Supply 3.3-5 V Bus I2C I2C address 0x40 / 0x41 / 0x44 / 0x45 Measures current, voltage, power

Pins and ESP32 wiring

PinRoleESP32 pinNotes
VCCPower3V3
GNDGroundGND
SCLI2C clock (SCL)D22
SDAI2C data (SDA)D21
VIN-Not wired to the ESP32—To the load. Measured circuit only, up to 26 V
VIN+Not wired to the ESP32—From the supply. Measured circuit only, up to 26 V

Suggested wiring for the 30-pin ESP32 DevKit, avoiding flash, input-only and strapping pins. BoardPilot checks it for you as you wire.

Starter code (Arduino)

#include <Wire.h>

void setup() {
  Serial.begin(115200);
  Wire.begin(21, 22);  // SDA = GPIO 21, SCL = GPIO 22
  Wire.beginTransmission(0x40);
  bool found = Wire.endTransmission() == 0;
  Serial.println(found ? "INA219 current + voltage monitor found at 0x40" : "Not found: check power, GND and SDA/SCL");
}

void loop() {}
